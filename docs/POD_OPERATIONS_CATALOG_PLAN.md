# 第 6、7 步实施计划

范围：管理任务/批次元信息、有限日期用量、取消/停止、指定资源私有访问授权，以及独立平台素材和官方模板。

1. 复用 008 的管理动作、审计和私有授权；功能权限和事务内权限复核都保留。默认列表不含用户正文、项目名、节点输入输出或供应商原文。
2. 管理取消复用原执行状态机和 gate 锁，管理停止复用批次份额释放规则；不冒充 owner、不提供收费恢复或未知费用释放。
3. 私有授权限定 operator/owner/单个 run 或 asset、用途、最多 24 小时；读取前同步记录安全审计，root 仍需 grant，撤销立即影响后续读取。
4. 012 新增六张官方模板表。平台素材位于私有存储根下独立 catalog 根，普通个人文件接口不能读取；上传要求使用权说明。
5. 模板独立不可变版本、明确发布/下架。用户使用固定已发布版本，先持久化复制计划和空间预留，再复制校验文件，最后事务创建个人素材、项目及引用。重试复用原请求/文件键，不能重复占空间或创建项目。
6. 管理端沿用 Element Plus、原 size 与紧凑表格；创作端沿用银灰/钴蓝和现有模板入口，添加官方模板 Tab。私有内容不持久保存到浏览器草稿。
7. 先用 011 完整备份在独立副本演练 012，再迁移本地专用库；补鉴权/撤权/幂等/失败恢复/账实一致测试、两端构建、真实页面及完整备份恢复。

查询统一分页，上限 100；任务/用量日期最多 31 天，排序末尾唯一 ID，聚合集合查询。所有新表保留五个审计字段，所有 I/O 使用 context 和超时。错误复用业务 code，响应 camelCase，金额与 ID 用字符串。
本轮不调用真实模型、不提额、不改 ERP/门户或原业务库。支付和官方模板市场不属于本轮。
