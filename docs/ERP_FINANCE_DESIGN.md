# 采购财务基础008：设计与实施清单

日期：2026-10-24。仅erp、本地ruoyi_go_mt、自有web；本页不是验收结果。

## 1—5范围

1. 明确会计以外的业务记账规则，新增008独立CREATE，不改001—007。
2. 企业内部资金账户、按已过账收货批次显式登记应付及不可变原行价格快照。
3. 原批采购退货独立抵减、分次付款/同供应商同币种多应付核销、整笔付款冲销。
4. 账户/应付/付款/供应商对账页面及独立财务权限、受控导出。
5. 金额/并发/幂等/故障/隔离/撤权、页面、全量回归、配套恢复和如实验收报告。

## 金额与来源

- 一个应付对应一个不可变采购收货批次。只有人工明确选择才登记，包括历史批次；安装/启动/收货不自动补账，不把采购未收部分登记为应付。
- 使用采购确认冻结的单价×该收货批次原行数量，保存独立应付行快照，DECIMAL(20,4)字符串定点计算，拒绝溢出。零单价允许，零额应付允许；付款及核销必须正数。
- 已发生的原批采购退货以不可变抵减记录登记，保存原returnId及原价金额；不修改原应付毛额、不回写采购/库存事实。每次最多100笔明确returnId，不能重复抵减。
- 付款前有未登记采购退货则拒绝，要求先核对抵减；供应商锁与现有退货串行，避免核销期间新退货穿透检查。
- 净应付=毛应付−退货抵减；待付=max(净应付−有效已付,0)，超付=max(有效已付−净应付,0)。后续退货可产生超付，不能阻断真实退货，也不能静默算成退款；本期无供应商退款登记。
- 一个付款固定一个内部账户、供应商、币种、1—100个不重复应付；金额必须恰好等于核销合计，各行不能超过当时待付。不支持预付款、余额挂账、跨币种、汇率、银行接口或现金余额保证。
- 付款直接确认；已确认不能删改。整笔冲销仅撤销本系统的付款记账/核销，保留原记录、原因及版本，不表示银行退款/撤销转账。
- 账户仅内部编码、名称、类型、币种、启停，无真实银行卡号。编码/类型/币种创建后固定；修改名称/状态需版本。账户统计不是银行实时余额。

## 隔离、权限及隐私

- erp:financeAccount:list/query/add/edit；erp:payable:list/query/add/adjust/export；erp:payment:list/query/add/reverse；erp:financeStatement:list/export。
- 财务开通和功能权限独立于收货/采购query；财务来源接口按自己的权限输出必要价格，不返回供应商联系人/收件资料。收货和采购退货原无价格DTO不变。
- 应付、收货来源、退货抵减始终按当前仓库范围。付款须拥有其全部核销应付仓库；只拥有部分不能读付款头总额或详情/重放，列表也不展示。对账仅汇总当前可读应付，明确是范围内数据，不是全企业余额。
- 平台不能代入企业，客户端不传tenantId；业务表及所有FK包含tenant_id，异步/导出同范围。账户企业共享但财务功能权限仍独立。
- 新菜单只登记定义，不给现有企业/角色自动开通；只有当轮新测试企业可按持续授权分配资源，结束撤权、恢复验证码、停用保留。
- no-store、不挂通用正文日志/防重缓存、不把价款/备注/付款内容存入浏览器持久缓存；审计只记录动作/ID/版本，HTTP不记录财务查询串。

## 并发与重试

- 写事务READ COMMITTED，先锁员工；来源操作按供应商→采购→原收货→应付；付款按供应商→账户→付款(若已有)→有序应付，供应商锁将同供应商来源抵减/退货/核销串行。不得取得应付后反向锁采购/收货。
- 引用仓库仅做当前范围校验，不加仓库写锁；财务不改库存/采购事实。付款反冲不因主数据停用而禁止，但仍要求当前身份、功能及全部仓库范围。
- 每个写动作持久version/requestKey；不可变请求指纹含操作者/动作/目标/版本/规范内容。成功原结果与业务/核销/最小审计同事务。同键异内容拒绝；重试先查当前范围再返回原结果，不返回最新状态，不重复付款。
- 页面确认前冻结原请求；未知结果显式原键重试，不能刷新后自动换键/版本。关闭清空详情并使晚响应失效，遇撤权不能回显旧价格。

## 升级与验收门槛

- 启动只读校验：全无可选，部分/孤立记录/漂移拒绝；显式本地CLI要求新鲜配套备份及恢复报告，共享ERP迁移锁，不自动修复已登记缺表。
- 普通资料CRUD从实际新表调用现有生成器，保留原ZIP；领域过账由repository单事务实现，生成菜单SQL不直接执行。
- 新表索引覆盖租户/来源/供应商/币种/仓库/核销关联，列表稳定主键排序、pageSize<=100、输入明细<=100。导出MaxExportRows+1拒绝超限，不截断，价格权限不由前端隐藏代替。
- 不含销售结算/退款、总账/税/凭证、成本利润、多法人/汇兑、真实银行API、远程/生产/容量认证。
