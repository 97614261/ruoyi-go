# 有界批量与第一版交付

本轮实现第 3 项和第 5 项。批量是固定模板版本的一组明确输入，不做输入之间的笛卡尔积。

## 执行约束

- 每批 1—10 项；个人最多 20 项、实例最多 200 项尚未派发的输入。创建、停止、派发共用执行门和空间锁。
- 创建前由服务器校验全部输入并预览调用次数、生成图片数、累计预占估算。预览不扣款、不占预算；逐节点领取时仍检查现有预算和并发上限。预算不足允许部分成功。
- 模板版本和每项绑定图不可变；待派发素材保留独立引用。派发事务创建独立项目、运行、outbox 并绑定批次项；崩溃不会重复创建。
- 停止仅取消尚未派发项；已经派发的运行仍可在运行详情取消。恢复只通过已有运行接口，限已确认失败；待确认计费调用不得自动重发。
- requestId 和规范化内容摘要保证创建幂等；结果未知时浏览器保留原请求重试。改变执行模式不转换旧批次。
- ZIP 只包含本人批次已成功节点的本地归档图片，按项目及 print/mockup 分类；最多 100 张、总原始字节 100 MiB、生成超时 30 秒、实例最多两个同时打包。返回完整临时 ZIP 后清理。

## 接口检查

1. 列表分页最多 100；单批详情最多 10 项。
2. 空间+创建顺序、派发状态+轮转时间、批次项序号、素材反向引用均有索引。
3. 列表不逐项查运行；详情、ZIP 使用集合查询。工作器每 tick 至多派发一项。
4. 数据库请求 5 秒，创建 10 秒，ZIP 30 秒；沿用请求取消。
5. 全部接口要求 pod:studio:access、本人有效空间及成员资格；素材和结果不接受客户端存储路径。
6. 业务错误不回传 SQL、密钥、凭据、供应商 URL；ZIP 不包含内部回执。
7. JSON 使用 camelCase，数据库编号和 micros 金额均使用十进制字符串。

## 界面

沿用现有 Manrope、白/银灰画布、钴蓝操作色。批量入口位于模板详情，批次列表位于运行页标签，不新增后台菜单。输入按一项一组紧凑显示，确认区域集中显示份数和调用预估。

```text
模板详情 [单份使用] [批量制作]
  固定版本 vN
  01 名称 / 文本输入 / 图片选择     [复制输入] [删除]
  02 名称 / 文本输入 / 图片选择
  [+ 添加一份]
  服务器预览：份数 / 调用 / 图片 / 预占
  [确认模型费用] [开始批量]

运行 [历史] [批量] [我的用量] [测试额度]
  批次名称 / 总份数 / 状态 [查看]
  每项状态 [打开项目] [运行详情]
  [停止待派发项] [下载已归档图片 ZIP]
```

## 交付验收

先备份原库；安装新增 007，不回写 001—006。补批量隔离、幂等、停止竞争、重启派发、失败和未知计费测试，运行完整 Go/前端测试。
进行实际登录页面链路、少量真实模型（新增估算不超过 1 元、保持实例原有累计预算）、CPU 图片时间/内存检查。
另建恢复数据库与素材目录验证完整备份，恢复副本不启动 Worker、不连接原队列。交付文档分别记录本地已测、供应商账单未核实、Linux/真机未测。
