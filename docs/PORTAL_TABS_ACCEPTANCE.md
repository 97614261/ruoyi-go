# 门户后台Tab与用途澄清验收（2026-11-03）

本次是本地18085、portal分支的页面调整快照。原API、数据库schema v16/58表、资料发布和四类审核策略不变；不涉及远程服务器。

## 三个功能的用途

- 内容标签：文章/产品的多个主题分类、前台标签筛选和发布名称快照。系统字典可以作为固定选项或未来候选来源，但直接替换会丢失现有关系/快照语义，本轮保留业务标签。
- 前台访问统计：后台只读报表，统计前台文章、产品、单页、首页、栏目等成功HTML访问。后台页、管理接口、私有预览不计入；刷新和机器人会计数，是PV，不是UV。页面增加类型列和明确说明，统计算法未改。
- 询盘数据保留与审计：手动擦除过期询盘和追踪策略、导出、预览、清理的操作者/行数/文件SHA；不是全站备份或自动删除文章。默认0天不限期，设置策略本身不擦数据。

## 页面改动

| 页面 | 分类Tab |
|---|---|
| 站点与外观 | 基础与外观、导航与轮播、首页组件、列表布局、统计设置、发布历史、站点巡检 |
| 数据保留与审计 | 保留设置、手动清理、清理记录、操作审计；按完整权限显示 |
| 协作设置 | 协作规则、影响范围、变更记录 |
| 行业模板与页面预设 | 选择方案、变更预览、应用记录 |
| 访问统计 | 每日访问、内容与页面排行、访问来源、站内搜索词 |
| 文章/产品/单页 | 全部、未发布、已发布，仍传原数字发布参数 |
| 栏目、标签、旧链映射 | 栏目类型；标签/映射启停状态，仍用原筛选字段 |
| 审核、询盘、消息、索引 | 审核状态、询盘状态、全部/未读、索引状态 |
| 工作台 | 我的草稿、失败任务、前台访问趋势 |
| 询盘详情/导出/运营分享弹窗 | 留言处理/指派跟进/时间线；导出文件/记录；内容设置/分享/预览 |

下载中心原有“资料管理/分类管理”保留；素材等单列表无需强行增加Tab。主题对比保留左右对照。切Tab不保存、发布或清理；共享表单保留未保存内容，记录按需读取。切列表分类重置页码，其他筛选仍可使用。
