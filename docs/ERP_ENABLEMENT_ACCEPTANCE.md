## 实现

- 菜单9500/`erp:setup:list`、所有者专属GET `/erp/setup`，固定16项存在性检查。按人员与授权、业务资料、第一笔业务分组，并跳转原页面。不新建业务表、索引、012迁移或一键自动授权/入库/记账。
- 读取同一只读快照，先核实服务端企业/当前所有者，再读元数据，最后固定一条带企业条件的EXISTS组合查询；不按员工/仓库/结果行循环查库。各子查询及关联显式tenant_id。
- 缺功能不读取其业务存在性；缺模块与DB错误分开。接口只给key/state/checkedAt，不给人员、价格、凭据、客户资料或资源ID。平台、员工、跨企业参数不能代入客户检查。
- GET `/erp/setup/roleTemplates` 限所有者及新增角色权限，返回五个固定模板。仅本企业可授权目录求交集，显式列出不可用权限，不含平台/系统管理/范围授权和通配符。原角色POST再次校验。
- 前端只在新增角色时预览/精确预填，不保存角色、不分配员工/范围；父子联动关闭。弹窗防晚响应覆盖，预填期间禁止保存，启用页失败/失活清空旧结果。
