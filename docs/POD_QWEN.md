## 2. 在本机配置

先在百炼控制台创建北京地域 API Key、开通对应模型，并设置供应商侧预算/告警。密钥只放服务端，不发到聊天，不写入节点或 Git。
模式切换前先停止本项目 API/Worker，核对现有运行；已发出的真实请求即使关闭窗口或停止 Worker，也可能继续计费。

在忽略提交的 `configs/pod.local.yml` 中修改现有 `pod` 配置，不新增第二个 `pod` 根节点：

```yaml
pod:
  execution:
    mode: qwen
    # 保留原有并发与等待上限；初次试跑建议三项并发均为 1。
  qwen:
    baseURL: https://dashscope.aliyuncs.com
    apiKey: "在本地填写你的 API Key"
    apiKeyEnv: DASHSCOPE_API_KEY
    allowPaidCalls: true
    budgetFen: 500 # 当前本机累计估算预算 500 分，即 5 元；其他环境应自行明确额度。
```

只允许北京地域官方 HTTPS 根域名，不填写 `/compatible-mode/v1` 等路径。
新控制台如提供专属地址，也支持 `https://工作空间ID.cn-beijing.maas.aliyuncs.com` 形式；请复制控制台实际工作空间 ID，示例中文字不是有效域名。
其他地区的密钥、模型与价格不能直接套用这份配置。

支持直接在这个本地文件填写 `pod.qwen.apiKey`，填好后重启 API/Worker 即可。
该文件已被 Git 忽略，不要把真实密钥填到 `pod.example.yml`。配置文件是明文，应限制其读取权限。
`apiKey` 非空时优先使用；为空时读取 `apiKeyEnv` 指定的环境变量。填写了无效密钥会报错，不自动改用另一份密钥。

如果选择环境变量方式，把 `apiKey` 留为空字符串 `""`，在用于启动服务的同一个 PowerShell 窗口设置：

```powershell
Set-Location D:\WorkSpace\CodeX\pod-studio
$podKeyInput = Read-Host '请输入百炼 API Key（不会回显）' -AsSecureString
try {
  $env:DASHSCOPE_API_KEY = [System.Net.NetworkCredential]::new('', $podKeyInput).Password
  .\scripts\pod.ps1 -Action start
} finally {
  Remove-Item Env:DASHSCOPE_API_KEY -ErrorAction SilentlyContinue
  $podKeyInput.Dispose()
}
```

Worker 从启动时继承的服务端环境读取密钥，父终端随后清除不会撤回子进程已继承的值；下次重启需重新输入。
API/Worker 必须同时使用相同配置；密钥不放进前端环境变量、节点、命令参数或可提交的示例文件。
`scripts/pod.ps1` 启动前仍需完成本地 Go/Node/MySQL/Redis 配置，见 [本地运行](./POD_LOCAL.md)。

## 3. 怎么使用

1. 登录创作端，建立「文本输入 → AI 生图」，也可从左侧插入工作流预设。生图节点必须有文字输入。
2. 在文本输入写设计要求，可点节点内“AI 润色”，确认付费后预览，再选择替换原文或保留。独立 AI 文本仍在进阶节点中，文字生成不支持看图。
3. 直接在生图节点设置比例、数量和补充提示词。参考图用图片输入节点连接生图的图片端口。
4. 点击生图节点“立即生成”并确认付费，先保存画布再执行该节点及全部上游；上游 AI 会重新调用并计费。需要整条流程或复用历史上游的单节点模式时，打开“执行流程”。
5. 在运行详情查看文字、图片、模型、Token/图片用量和估算费用；生成图片会归档到本人私有素材库，可继续选择或下载。

节点内操作复用可靠运行队列。润色不会自动增加画布节点，关闭弹窗不会取消已提交调用；
原文已修改时禁止用旧润色结果覆盖。具体保护及本轮自动化证据见 [节点交互记录](./POD_NODE_INTERACTIONS_20261112.md)。
节点内 polish/branch 已有真实成功运行及 API 复核；完整已登录浏览器页面验收仍须另做，不能用接口小样本代替。

文字输入与指令合计最多 32000 字节，输出最多 2048 Token；组合后的生图提示词最多 1200 个字符。
每次生图 1—4 张，参考图最多 3 张；本地上传的每张图片还受字节数和像素限制。
比例映射：1:1 为 1024×1024，3:4 为 960×1280，4:3 为 1280×960，9:16 为 720×1280，16:9 为 1280×720。
五种比例已有真实尺寸核对；1—4 张及 0/1/3 张参考图的参数组合有替身测试，其中单参考图与两张输出已做真实样本，其余组合不宣称已实测。

单节点执行只复用同项目、同版本、同模式的成功上游结果。已保存的运行固定模式和模型，不随当前配置切换。
前端发送 `executionMode: "qwen"`；不带该字段的旧请求不能自动变成付费请求。
恢复已确认失败的真实步骤也可能再次收费，需要另行勾选恢复确认；已成功节点继续复用。

## 4. 预算和故障怎么理解

`budgetFen` 接受 1—5000 分，是整个 POD 数据库内所有用户的**累计估算上限**，不是每用户余额，也不是每日/月度自动重置。
已确认用量估算与未知调用的预占共同占用预算。文字每次先预占 0.025 元，图片每张先预占 0.10 元；确认后按用量估算结算。
因此余额即使够实际生成少量文字，也可能不足以通过保守预占。更改配置只改变上限，不清空已有累计记录。
固定价格与实际账单可能不同，该限制不能替代百炼侧额度控制；「测试额度」只属于模拟模式，不能抵扣真实费用。

| 情况 | 处理 |
|---|---|
| 模型明确拒绝请求 | 记录失败，释放本次预占；检查开通、密钥、参数或限流后再决定是否恢复 |
| 403 且精确错误码 AllocationQuota.FreeTierOnly | 免费额度耗尽且供应商仅免费调用；显示固定提示，请部署者在百炼核对付费设置。本站预算不会自动启用付费，不自动重试 |
| 网络超时、响应丢失、进程中断 | 保留待确认与预算，不自动重发付费请求 |
| 图片已生成，下载失败 | 保存供应商结果后只重试下载，归档按调用和图片序号去重 |
| 已归档，但节点完成回写丢失 | 复用调用记录和已有素材，不再次生图或下载 |
| 部分文字或图片返回 | 保存已确认用量和可用结果，标记失败，不当成完整成功 |
| 取消流程 | 停止未开始步骤；已开始调用继续确认，可能计费 |

同步接口没有已验证的客户端请求键幂等/查单保证。未知调用需要结合供应商明细人工核对；当前没有人工确认、释放预占的操作页面。
供应商签名图片地址通常约 24 小时过期；错过归档窗口后可能无法恢复，当前也没有刷新地址功能。
遇到长期待确认先保留记录并核对供应商，不能通过直接改状态、删表、清空预占或自动重新生成来处理。

运行详情展示当前节点结果；“运行与用量 → 我的用量”按每次运行汇总所有恢复尝试的累计估算费用、
预占、模型调用和已确认生图数。它不是供应商账单，不能据此推算实例剩余额度；图片数包含尚未归档的结果。
只返回本人数据，不返回全局已用、余额或供应商私有响应；人工结算入口仍未实现，见 [用量报告](./POD_USAGE_REPORT_20261112.md)。
素材采用保留式删除，数据库提交结果不明时可能留下待核查孤立文件，尚无物理清理任务。

## 5. 首次真实验收清单

先确认本机密钥已配置、模型已开通，并明确本次小额预算；再进行以下样本，不能用真实生图做无限压测：

1. 一次短文字生成，核对输出、Token、返回标识及控制台明细。
2. 一次单张文生图，检查实际尺寸、私有素材归档、下载与账单。
3. 一次单张参考图生图，检查参考图和规格是否真正生效。
4. 刷新后检查历史，再用另一账号确认不能读取这些素材或运行。

按当前估算，前三项基本调用约 0.2 元加少量文字费用，失败、重试或供应商价格变化另计。
执行后记录模型、时间、结果、实际用量和费用，不记录密钥或签名下载链接。
2026-11-12 已完成短文字、单张文生图、单参考图、五种比例及两张输出和另一账号隔离，包含原图下载；
2026-11-13 已补真实登录的本地制作/批量与下载文件检查。供应商账单仍未核；3/4 图和多参考成功样本受免费模式阻塞。
不能把已有样本当成所有尺寸、参考图组合和故障场景均已真实通过，也不能把本地制作成功说成当日真实生图成功。

恢复模拟模式时将 `mode` 改回 `simulation`、`allowPaidCalls` 改回 `false`、`budgetFen` 改回 `0`，并重启 API/Worker。
这只停止新的真实提交，不会取消已被供应商接收的调用；尚未完成的真实运行要回到千问模式继续核对。
