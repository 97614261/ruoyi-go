# 门户第3步验收：文章、单页与发布

2026-10-29；portal 分支，本地 Windows / MySQL 5.7 / Redis DB14。
本报告是本次验证快照；开发状态见 PORTAL_PLAN，历史第1、2步报告不作为当前结构说明。

## 已交付

- 后台「门户管理 → 文章管理 / 单页管理」，独立 list/query/add/edit/publish/remove 权限。
- 富文本草稿、私有素材图片、封面、摘要、作者、SEO字段和修订备注。
- 保存生成不可变修订；线上读取已发布指针，编辑草稿不改线上。
- 独立发布、下架、草稿预览、分页历史；恢复历史会复制为新草稿，不自动发布。
- 首次发布后访问地址锁定；删除停止公开并保留历史，历史地址继续占用。
- 栏目历史引用保护；有内容历史的栏目不能删除或更改类型，可以停用。
- 正文只允许登记素材的 /media/ID 图片；服务端读写双向净化，禁止外部图片/iframe，最多256KiB和32个图片引用（含封面）。
- 内容写操作日志省略请求和响应正文；CMS SQL日志不展开绑定参数。

## 本地入口与公开边界

后台：http://127.0.0.1:8085/admin/ 。账号仍在忽略文件 logs/portal-accounts.local.json，本文不记录密码。
文章 /news/:slug；单页 /p/:slug；图片 GET/HEAD /media/:id；公开摘要 /portal/articles、/portal/pages。
未发布、已删除内容不公开；文章还要求所在栏目和全部祖先启用。
图片只有被有效发布版本引用才公开；校验先于条件响应。新请求下架后返回404；此前已下载的图片无法收回。
正文预览通过无脚本沙箱iframe和鉴权Blob展示，不在URL传Token；关闭页面释放Blob。

## 数据库与升级

本地 ruoyi_go_portal 显式从v2升级v3，新增 cms_content / cms_content_revision，共26表。
文章/单页工作与发布指针用复合外键约束所属内容；旧 sys 表结构不变，没有向普通角色自动授予菜单。
升级前备份：logs/portal-step3/pre-v3.local.sql。升级后备份见同目录 accepted-v3.local.sql。
原系统库、ERP库和参考Vue源代码未修改。

升级入口默认只预览：GOWORK=off go run ./cmd/portalmigrate。
人工确认备份并停门户后才执行：GOWORK=off go run ./cmd/portalmigrate -confirm。
工具仅接受本地专用门户库，先核验旧版本指纹，再逐版本升级、登记新指纹；失败保留现场，不自动回滚DDL、重放或清库。
新安装器只接受从未存在的库，安装到当前版本；它不能用于重建现有库。启动只读检查结构，永不自动迁移。
