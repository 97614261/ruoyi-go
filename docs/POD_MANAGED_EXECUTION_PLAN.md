# 第 5 步实施计划

范围：创作端模型选择、服务端报价、managed 执行、正式点数消费；保留旧 qwen/simulation 的历史与账本。

1. 新增 011：报价、执行快照、节点模型绑定、调用计费；先在独立恢复副本验证，再安装本地开发库。
2. 后端：本人可用模型、报价与确认；单次/节点/分支/润色/恢复/批量统一固定版本与计价，事务预占及幂等。
3. Worker：按绑定规格及凭据版本执行；成本和点数独立预占/结算；取消只释放未提交份额，未知调用不重发。
4. 创作端：节点选模型、服务器报价确认、正式点数与执行状态；沿用现有页面风格，不做新后台模块。
5. 验收：离线适配器与本地数据库测试、竞争/幂等/拒绝/恢复/批量停止、旧链路回归、构建、完整备份恢复及页面检查。

本轮不自动录入真实 API Key、扩大现有模型预算或发起付费生成。测试在本地专用数据及替身供应商中完成。
真实供应商、目标 Linux、账单和印刷质量结论沿用已有报告的未验收边界。
