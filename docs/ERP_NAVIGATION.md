# ERP业务导航分类

自有前端侧栏按业务域分组，经营概览和企业启用直接展示，其余使用可折叠分类。

| 一级入口 | 页面 |
|---|---|
| 经营概览 | 经营概览 |
| 商品管理 | 商品档案、商品分类、商品SKU |
| 店铺与渠道 | 渠道目录、店铺管理、店铺商品配对 |
| 采购管理 | 供应商管理、采购单、采购收货作业、采购收货记录、采购退货 |
| 订单管理 | 订单录入、订单导入任务、包裹发货、订单退货入库 |
| 仓储管理 | 仓库、库存余额、库存流水、拣货与打包、仓库调拨、库存盘点、采购入库、销售出库、采购退货/冲销、销售退货/冲销 |
| 物流管理 | 物流设置、发货记录 |
| 财务管理 | 财务资金账户、采购应付、采购付款、供应商对账、销售应收、销售收款、店铺对账 |
| 企业启用 | 企业启用检查 |

“采购入库/销售出库/退货冲销”为原手工库存凭据页面，放在仓储作业内；正式采购收货/采购退货在采购管理，订单关联退货在订单管理。页面名称和原业务约束保留。

## 图标

2026-10-29统一采用24×24、currentColor线条SVG：概览用趋势图、商品用货箱、店铺用门店、采购用入库单、订单用单据、仓储用仓库、物流用货车、财务用账本、企业启用用校验盾牌。一级分类使用业务域图标；二级功能页各用独立图标，例如SKU用条码、商品分类用树、采购单用采购车、收货作业用入库托盘、收货记录用勾选单据、库存流水用账页、调拨用双向箭头、盘点用清点表、拣货用扫描框、资金账户用钱包、付款/收款用不同方向箭头。统一跟随主题，不增加图标库依赖。

二级图标由erpNavigationPageIcons按真实页面标识映射，仅处理后端已授权页面。未知扩展页面保留原图标；经营概览、企业启用仍为直接入口。新增二级页需同步维护映射及src/assets/icons/svg/erp-*.svg。

资源和原菜单授权/路径元数据有自动化检查；本轮没有计入真实侧栏视觉验收。详见[前轮记录](./ERP_UI_REVIEW_2026-10-29.md)。该记录的包体数字为二级独立图标补充前的构建快照。

### 二级菜单图标补充

2026-10-29按用户补充要求，为全部34个二级功能页分别配置图标；一级分类不再覆盖二级页面图标。只改自有前端导航展示和SVG资源，不改菜单授权、页面地址或数据库。本轮259项前端测试及生产构建通过，并核实34个二级图标全部进入构建后的SVG sprite；原资源、路径/授权元数据及少权限菜单回归通过。验证结果见本地logs/erp-leaf-icons-20261029/。浏览器视觉验收仍按用户选择延期。

## 实现边界

- 分类仅作用于自有web的侧栏和面包屑。真实Vue Router注册、页面组件、`/erp/...`地址、查询参数、菜单ID及权限字符串保持原样。
- 数据库菜单及平台开通树仍是既有授权目录；这次不增加数据库目录节点，不改表、不移动授权、不替已有企业或员工开通功能。
- 侧栏只分类后端已返回的菜单；没有权限的页面不补齐，没有可见页面的分类不显示，平台账号继续不显示客户ERP。角色仅有一个页面时仍保留业务分类，以便定位。
- 分类容器的`/__erp-navigation/...`只是侧栏展开索引，不注册为真实页面，也不作为业务跳转或可点击面包屑地址。业务叶子保持真实绝对地址，避免虚拟分类路径拼入URL。
- 新增或自定义ERP页面尚未登记分类时保留在“其他ERP功能”，防止更新后入口丢失。添加模块时同步更新`web/src/utils/erp-navigation.mjs`中的展示分类。

开发环境前端热更新后刷新页面即可加载；生产环境需重新构建并发布前端。已有运行包不会自动包含本次导航修改。
