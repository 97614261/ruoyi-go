# POD 执行交互简化

日期：2026-11-17。本报告为本轮修改与验收快照，当前操作说明见 [使用说明](./POD_USER_GUIDE.md)。

## 用户问题

- 截图最后的“下载改图 PNG”是结果导出节点：按文件名、格式和用途保存上游图片，导出本身不扣模型点数，不会额外提升图片清晰度。
- 截图 Pro 型号为每张 25 点；该流程只有一次生图、生成 1 张，模型部分为 25 点。输入和导出无模型费用。单独点击 AI 润色会另计文字用量，价格以对应版本及服务端报价为准。
- “生成导出文件”仍是节点及上游执行，包含 AI 上游时会重新调用并计费。已有图片直接点击结果旁“下载”即可，不应为下载再次执行上游。

## 修改

| 入口 | 当前行为 |
|---|---|
| 画布立即生成、AI 润色、开始制作、生成导出文件 | 点击后自动保存、核价、提交，弹窗直接显示进度与结果 |
| 执行面板整条流程、单节点 | 点击执行后自动核价提交 |
| 恢复失败步骤 | 点击恢复后自动获取新报价并提交；未知请求继续原操作 |
| 批量制作 | 保留份数预览与开始按钮，开始后自动核价，不再叠加报价确认 |

移除 `ExecutionQuoteDialog.vue`，统一由 `execution-quote.ts` 请求和校验服务端报价。报价仍由后端绑定输入、模型和不可变费率；没有调整单价、预算、数据库、权限或真实凭据。旧 qwen 模式的费用确认保留。

防重复与失败处理继续有效：

- 只在用户本次点击后自动执行。刷新、重开历史结果和网络恢复只读原状态。
- 报价失败、格式异常或过期不提交；等待保存/报价时输入变化或关闭页面不提交。
- 连续点击由 busy 拦截；创建运行前持久化原请求。
- 提交结果未知时保留原内容、requestId、quoteId，显式重试原操作，不重新报价或自动重调模型。
- 润色结果仍由用户决定是否替换原文，不自动覆盖编辑内容。
