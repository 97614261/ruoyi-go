## 3. P2-10 业务唯一性检查存在并发竞争（暂缓）

用户、角色、岗位、参数、部门、菜单仍采用 `COUNT` 后写入。两个并发请求可能同时通过检查
并产生重复数据；Java 存在同源缺陷。生产数据库结构冻结，后续只能评估 MySQL 命名锁、
Redis 分布式锁或应用层串行化，不能用新增唯一索引绕过边界。
