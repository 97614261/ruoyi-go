## 做了什么

入口：**工作流模板 → 我的模板 → 使用模板 → 批量制作**。先选固定版本，逐份填写文字或选图，
点“核对份数与费用”，确认后提交。在 **运行与用量 → 批量** 查看每份进度、打开独立项目、查看运行和下载 ZIP。

- 每批 1—10 份，每份对应一组明确输入；复制输入后可分别修改，不自动组合成笛卡尔积。
- 模板版本和绑定后的每份图固定；模板后来更新不影响旧批次。尚未派发的素材也保留引用。
- 服务器预览份数、文本/图片调用数、图片数和累计预占估算；预览不预留预算。
- 每人最多 20、实例最多 200 项待派发。逐节点执行继续使用原并发与累计预算，可能部分成功。
- requestId 和规范化摘要保证创建幂等；网络结果不明时保留原内容、原编号重试。
- Worker 每 tick 最多派发一项，事务内同时建立独立项目、运行、outbox 和批次关联；队列满时轮转检查。
- “停止待派发项”只取消尚未派发的份数。已派发的运行在运行详情取消，已发生调用仍需确认费用。
- 恢复沿用原运行接口，仅对明确失败执行人工确认后的恢复；未知调用不能自动重发。

批次状态 `active/dispatched/stopped` 表示派发进度。“已全部派发”不表示全部制作成功；
每项状态读取实际运行，已成功结果单独保留。

## 接口与数据库

六个接口均要求登录、`pod:studio:access`、本人有效空间及成员资格：

| 接口 | 用途 |
|---|---|
| `GET /pod/batches` | 稳定分页，页大小最多 100 |
| `POST /pod/batches/preview` | 校验全部逐项输入并计算影响 |
| `POST /pod/batches` | 固定版本、输入快照和幂等创建 |
| `GET /pod/batches/:id` | 最多 10 项的派发和实际运行状态 |
| `POST /pod/batches/:id/stop` | 停止待派发项 |
| `GET /pod/batches/:id/download` | 本人成功归档图片 ZIP |

## 已验证

`test/pod/batch_test.go` 覆盖：

- 预览、无登录拒绝、跨账号读写/停止/ZIP 拒绝、11 项拒绝、执行模式不匹配拒绝。
- 逐项绑定互不污染；重复请求复用批次，同键不同内容拒绝。
- 派发一项后停止其余项，不破坏已派发运行；继续 tick 不派发已停止项。
- 并发重复创建、并发派发和后续 tick 恢复，独立运行不重复、不丢失。
- 实际创建 20 个待派发项，拒绝第 21 项；停止后容量释放并能再次创建。
- 空间停用后不派发，列表分页上限和 print/mockup 分类。
