# Studio 工作空间改版

参考：用户提供的 LibTV 四张截图。采用其导航、内容层级、画布操作区和中性黑灰视觉，保留 POD Studio 自己的品牌和已实现的功能。

## 设计约定

- 深色：侧栏/页面 `#121212`，画布 `#181818`，节点 `#202020`，次级区域 `#292929`，边界 `#353535`，主要文字 `#f1f1f1`。浅色使用同一结构的白/灰对应色。
- 主操作使用黑白反差，青色只用于链接、焦点和选中边界，避免把整个操作区做成蓝色。
- 字体沿用本地打包的 Manrope 与中文系统字库，品牌 22px、页面标题 22px、操作与正文 12—14px；不新增外部字体请求。
- 页面左对齐。首页只有一个主入口，项目缩略区突出画布身份，不把没有接口支持的封面当成真实生成结果。
- 只提供已有的模板、素材、节点、运行、账户功能。参考站点的促销、会员购买、社区、视频、音频、Agent 等不作为占位菜单加入。

## 范围

1. 新增首页，拆开首页与完整项目管理；保留原有项目和运行详情地址。
2. 重做固定侧栏、顶栏、项目列表、素材区域和移动端导航。
3. 重做画布悬浮顶栏与底部工具；高级操作收进“更多”，仍可通过按钮完成触屏连线。
4. 所有模式共用中性语义色；继续支持系统、浅色、深色，保留本地偏好。
5. 验收导航、创建入口、历史地址、读写权限与移动布局，不通过真实模型调用验证视觉。

本轮不修改后端接口、数据库、模型、单价、预算或执行幂等逻辑。

## 画布动效补充

同日按用户要求补充画布和连线反馈：

- 实线底轨叠加沿上游到下游移动的短光段，不同连线错开相位；只表达方向，不伪装运行状态。
- 悬停、选中连线或选择相邻节点时，相关线路使用青色底轨、柔和光晕与高反差流光。保留原 Bezier 端点和选择逻辑，透明点击范围为 24 个画布单位，装饰路径不拦截点击。
- 新连线的拖拽预览使用流动虚线；工具面板淡入 160ms，工具按钮按下时轻微收缩，不移动画布节点。
- “更多 → 动效”可暂停，选择保存在浏览器。实时响应系统减少动态效果设置；关闭后保留静态线路和高亮。
- 拖动节点、平移/缩放或页面不可见时暂停流光；超过 80 条连线时只保留交互关联线路的流光。不使用 JavaScript 逐帧循环，不新增依赖。

实现位于 `WorkflowEdge.vue`、`use-canvas-motion.ts`、`canvas-motion.css` 及 `ProjectEditor.vue`。渲染状态独立于保存图、revision、撤销栈和执行接口。

验证：24 个测试文件、181 项测试通过，类型检查与生产构建通过（原单包体积提示仍在）。新增回归检查曲线同步、点击区域与装饰层、偏好保存、动态系统设置、后台页暂停及监听清理、存储不可用，以及动效/视口变化不触发项目写入。

真实本地页面检查明暗主题、375×812 手机菜单、关闭后刷新保留偏好、恢复流动以及连线选择；读取计算样式确认 dash offset 随时间变化。没有调用模型或修改已有项目内容。系统减少动态效果的变化通过组件测试模拟，未改操作系统设置；本轮未做大图帧率压测或移动真机测试。截图：`.local/ui-workspace-20261117/canvas-motion-dark.jpg`。

## 2026-11-18 连线加号跟随

按用户最终确认，加号始终显示，不采用悬停后才显示的方案。鼠标进入加号附近的 68×68 画布单位区域后，圆形加号平滑跟随，最大偏移半径为 14；离开后回到原位。实际连线锚点留在节点边缘，不跟随装饰加号移动。

缩放按画布单位换算；开始连线、拖动节点、平移或关闭动效时停止跟随。触屏使用固定加号及 48×48 点击区域；系统减少动态效果设置同样关闭跟随，支持键盘 Enter / 空格连接。保留原端口数量、ID、方向及类型，不给输入节点增加虚构入口。

实现位于 `MagneticHandle.vue`、`magnetic-handle.css`，由 `WorkflowNode.vue` 与 `ProjectEditor.vue` 接入。组件回归覆盖偏移上限、两侧吸附中心、不同缩放、帧合并、退出/拖拽/禁用/卸载清理和键盘操作。

本地使用独立前端预览检查明暗主题、常显、关闭动效及外侧加号拖拽连接；跟随位移和缩放换算由组件测试验证。本轮未调用模型、修改数据库或已有项目。截图位于 `.local/ui-canvas-handles-20261118/handles-light.jpg`；完整前端测试与构建日志分别为 `.local/magnetic-handle-tests-20261118.log`、`.local/magnetic-handle-build-20261118.log`。
