## 跨模块链路与断言

| 链路 | 实际验证 |
|---|---|
| 官方素材与模板 | HTTP 上传平台图片及使用权说明，创建含文字、图片输入和指定模型的草稿，草稿对用户不可见；发布固定版本，相同请求重放不新增变更或审计 |
| 用户使用 | HTTP 复制已发布版本并替换文字，原请求重放得到同一个私人项目；图片复制为私人素材，其他账号读项目/图片均为 404，鉴权内容不能缓存 |
| managed 执行 | HTTP 报价、确认提交、原请求幂等；执行阶段注入离线替身，完成后再次执行也不新增供应商调用 |
| 点数与成本 | 样本输入 10、输出 5，按 fixture 固定费率实际消费 20 点、估算成本 20 micros；运行、个人账户及后台用量保持一致，剩余预占释放，调用记录只有一条 |
| 管理与隐私 | 发布审计保留操作者、目标和最终状态；任务元信息不含私人文案、结果、项目名、存储键或回执；root 无具体 grant 读取私有运行仍为 403 |
| 下架和撤权 | 下架后拒绝新复制，原请求仍能取回已完成副本；跨账号运行 404；撤回模型范围后新报价按现有契约返回业务码 409，本人历史运行仍可读 |
| 恢复不变量 | 创作者点数/存储账户、managed 账户及官方版本/复制归属校验同时通过 |

测试结束下架本轮模板、暂停本轮账号并停用模型，保留私人副本、费用、审计及必要预占证据。模型范围仅在本套件新建账号上撤回和恢复；不改既有 demo 等账号权限。
最初编写测试时修正了测试自身的字段类型、显式表名及错误码断言，没有为了测试改生产契约。
