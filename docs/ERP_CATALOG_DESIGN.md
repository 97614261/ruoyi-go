# 商品基础1—5

本文记录商品基础1—5的设计；本地开发及验收已收口，证据和限制见[ERP_CATALOG_ACCEPTANCE](./ERP_CATALOG_ACCEPTANCE.md)。范围为本地ERP商品档案，平台商品发布、采集、成本核算及条码扫描硬件另行设计。

## 数据与兼容

独立010新增分类、SPU、SKU档案、商品图片、幂等动作五表；001—009不变。SPU一对多SKU，保留原erp_sku作为库存/订单唯一SKU主数据。旧SKU不自动分组；可明确选择已有SKU归入商品，已有档案不允许转移/移除，删除走停用而不抹历史。商品编码企业内唯一；SKU编码保持原库排序规则；条码为企业内大小写敏感唯一的可空文本，保留前导零。重量克、长宽高毫米为可空正整数（未知用null），每项不超过1000000000。

每商品最多50个SKU、5图。规格/单位仍存原SKU，不重复存档。已有单据/库存/采购/店铺配对/订单/调拨引用的SKU编码、单位、规格禁止变化；商品编码归组后不变。名称可更新，不改历史单据快照。分类可停用，不物理删除；在用分类停用不影响历史读取。

## 权限、并发和重放

企业商品主数据按功能权限管理，属于企业共享，不按仓库/店铺筛选。平台身份不能读业务。erp:product:list/query/add/edit/import/export/image及erp:productCategory:list/add/edit独立授权；新菜单仅定义，不自动给已有企业授权。

写入先锁当前员工，聚合编辑再锁商品及按ID升序锁SKU；CAS版本防覆盖。所有写入携带企业内唯一requestKey，动作记录同事务落地；同键不同内容/不同员工拒绝，重试仍需当前权限，不绕过撤权。旧SKU接口对已归组SKU拒绝编辑/删除，要求从商品聚合操作；普通SKU保留原接口。

## 附件和导入导出

只关联当前企业已登记的PNG/JPEG/GIF/WebP附件；不取远程URL，不允许SVG/HTML。商品图片复用企业共享附件访问模型，并非按商品权限保密的私有图；撤商品权限不撤企业媒体权限。新上传走独立image权限路由和原配额/文件校验，未保存图片仍保留附件，不假装事务能回滚物理上传。

导入仅新增、不覆盖、不导入图片。XLSX模板每行一个SKU，同商品编码合并SPU；最多100行、10MB，严格表头/文本编码，重复编码/条码/冲突SPU字段整批失败。整批事务且同键可重试，失败不产生部分商品。导出按SKU展开，受统一最大行数保护，字符串以文本单元格输出，不执行Excel公式；导入未知分类拒绝，先建分类。

## 验收计划

先停本地写入，数据库与公开/私有附件配套备份并恢复新副本，010先在本轮新副本安装、对真实表运行生成器保存原ZIP后增强聚合。新增结构只读启动校验，损坏/部分登记拒绝。随后本地显式安装、接口隔离/重放/CAS/导入回滚/引用保护/附件测试，真实页面与四视口，完整两轮回归，最后再次配套恢复和测试企业收口。不连接远程、不改demo/旧密码、不提交Git。
