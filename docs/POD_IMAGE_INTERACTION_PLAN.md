# 图片交互优化设计

日期：2026-11-12。对应后续任务第 2 项；个人模板保持现有实现，本轮不开发批量。

## 范围与使用

- 图片处理参数面板增加原图上的框选、移动、四角调整、全图复位；保留数字输入和键盘调整。
- 预览先按 0/90/180/270 度旋转，再把选框写为现有 cropX/cropY/cropWidth/cropHeight，不另存像素坐标。
- 一次框选或复位作为一次编辑，撤销/重做及自动保存继续走项目草稿；取消手势不保存半成品。
- 图片处理结果旁增加“对比”，用归档素材 parentAssetId 查实际处理前图片；并排或单图查看，透明棋盘背景，可按像素放大检查边缘。
- T 恤增加水平/垂直居中、全部居中、布局复位及位置/像素提示；复位只改印花位置和大小，保留正反面与底色。
- 当前项目保留所选运行编号，刷新后通过原鉴权 GET 恢复并轮询非终态记录，显示本地任务状态与明确失败信息。

## 视觉与交互

延续现有紧凑创作工具，不新增菜单。Manrope 字体；纸面 #ffffff、画布 #f1f4f8、正文 #223249、辅助 #64758b、
主操作沿用系统 --accent（#3156d3），选框使用同一操作色。只有可编辑图像有选框，不为普通结果增加装饰。

```text
图片处理参数                 对比弹窗
处理方式 / 先旋转            并排 | 处理前 | 处理后     适应 | 100% | 200%
[真实输入 + 可编辑选框]      [处理前 + 像素尺寸]      [处理后 + 像素尺寸]
全图 / 选框像素尺寸          [棋盘底、可滚动检查]     [棋盘底、可滚动检查]
起点与宽高数字               来源：本次处理的直接输入；不修改原图
上次执行状态与失败原因
```

桌面与窄屏都把图放在参数上方；对比窄屏转单列。表单左对齐，按钮允许换行，不遮挡底部操作。
遵循 ui-ux-pro-max 的拖动替代操作与 Vue 清理建议：数字/按钮/键盘均可用；指针取消、换图、卸载时结束手势并释放对象 URL。

## 边界

本轮沿用既有接口和数据库 001—006，不新增 API、权限、节点配置字段或迁移。图片鉴权仍使用请求头，Token 不进 URL。
对比只读私有原图；不发模型请求、不替用户执行或重试未知调用，不改变 CPU 失败不得静默降级的规则。
旋转与裁剪使用服务端相同坐标系；提示像素按左右端分别向下取整计算，不能用“宽度比例×原宽”代替。
T 恤仍为二维示意，预览和服务端按同一印花区域与舍入计算，不承诺生产商验收。
本机保存的运行编号按账号/空间/项目隔离，不能选择别人的工作空间；401/404 不继续展示旧私有图。

## 验收

覆盖旋转后坐标、反向框选、四角缩放、越界拖动、取消/禁用/换图、数字非法值、一次操作一次撤销及保存后重载；
比较真实 parentAssetId、跨账号拒绝、原图加载失败、对象 URL 释放、像素缩放；居中/复位保留其他参数，前后端几何一致；
刷新恢复运行、错误重试、旧响应不得覆盖新选择、组件卸载停止轮询。执行前端全测/类型/构建、相关 Go 测试与必要 POD 集成，
使用本地模型或替身，不消耗千问预算。浏览器样例验收与真实登录链路分别记录。
