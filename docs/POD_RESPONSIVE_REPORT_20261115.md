# Studio 手机和平板适配验收

日期：2026-11-15。范围：创作端 Studio，保留现有配色、工作流数据和桌面操作方式。

## 本轮改动

1. 普通页面：平板导航独立一行，手机导航改为三列两行；项目、模板、素材、节点目录、运行、资格页面适配窄屏，长名称换行，分类按钮可换行。
2. 手机画布：顶部保留项目名、保存状态与三个操作；底部固定节点、模板、撤销、参数、更多，次要工具收进“更多”，避免横向滑动找按钮。
3. 浮动面板：手机参数、节点、运行面板放在底栏上方，有高度限制和内部滚动；窄屏一次显示一个工具面板，点击遮罩或关闭按钮收起。更多工具不会被参数面板遮住。
4. 触屏入口：支持点击添加节点，明确开启 Vue Flow 双指缩放、点击端口连接，增大端口命中范围。新增“更多 → 连线”表单入口并自动滚到该区域，保留不拖拽的操作途径。
5. 操作尺寸：触屏和窄屏常用按钮采用至少 44px 点击区域，表单文字使用 16px；缩放和适应画布按钮补充可访问名称。节点随画布整体缩放，其屏幕点击区域也会随缩放变化，可以通过参数和连线表单操作。
6. 弹窗与安全区：限制原生弹窗宽高，表单和按钮可滚动访问；官方模板预览在手机只保留外层滚动。加入 viewport-fit=cover、动态视口高度和刘海/底部安全区留白。
7. 修复实际验收发现的问题：320px 页面被 body 最小宽度撑出横向滚动、四个模板分类按钮超宽、运行页分类选择器未覆盖实际类名、参数面板与更多工具互相遮挡。

## 使用方式与验证边界

手机底部“节点”点击添加；“参数”编辑；“更多 → 连线”连接节点。画布空白处平移，双指缩放，标题拖动节点，也可以使用左下角缩放和适应画布按钮。详见 [使用文档](./POD_USER_GUIDE.md)。

真实 iOS Safari、Android Chrome 和实体平板上的双指手势、软键盘弹出、刘海安全区与系统下载行为仍需真机复核；本次浏览器视口验收不替代这些验证。
