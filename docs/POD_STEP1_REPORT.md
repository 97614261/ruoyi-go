POD 专项子用例：

1. 未登录访问 bootstrap 被拒绝。
2. 普通创作者返回自己的空间、七类节点及全部关闭的执行能力。
3. 两个普通账号拥有不同个人空间。
4. 客户端 workspaceId 参数不能指定另一个空间。
5. 创作者不能读取系统用户列表。
6. 创作者不能读取系统角色列表。
7. 系统管理员不能绕过 POD 空间成员关系。
8. 暂停成员后访问立即拒绝，用例结束恢复。
9. 暂停空间后访问立即拒绝，用例结束恢复。
10. 另一实例不能覆盖 Redis 归属标记。
11. 数据库实例标记不匹配时拒绝。
12. 已存在的目标数据库拒绝重复安装。
13. 验证码保持开启；测试产生的会话/验证码由用例处理。

这些用例只证明当前 bootstrap 边界，不代表尚未实现的项目、素材或运行接口已经验收。
