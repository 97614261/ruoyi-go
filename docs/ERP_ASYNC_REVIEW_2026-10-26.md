# 跨模块离页与未确认请求收口（2026-10-26）

本轮执行后续计划第1、2项：检查已有模块的离页保护和未知结果重试。已完成自有web的修复、专项/完整前端回归和构建；没有新增ERP业务模块或改后端契约。现状规则见[操作说明](./ERP_ASYNC_OPERATIONS.md)。

## 1. 覆盖范围与修复

| 模块 | 本轮处理 |
|---|---|
| 采购、收货、采购退货、销售退货、采购/销售财务、调拨 | 离页释放属于旧页面的锁，旧finally不得解锁重新进入后的新请求；隐藏页面不再启动读取/写入。原冻结请求逻辑保留并补回归 |
| 商品/分类、图片/导入、物流档案、供应商、库存预警 | 清理与异步锁归属补齐；旧商品/图片/文件结果不写回新页面。供应商及预警原目标/内容/版本固定 |
| 收货历史 | 缓存失活时阻止路由监听触发隐藏读取，保持原无价/价格权限边界 |
| 原库存单据 | 确认后、发请求前检查当前页面；详情与编辑读取加序号保护；草稿重试固定原内容与新建请求键 |
| 店铺商品及配对 | 校验/确认后检查归属；固定保存与配对的原目标/版本/内容，离页清理选项与草稿 |
| 仓库/店铺范围授权 | 旧确认不再在离页后写入；CAS重试固定原员工、范围和版本；关闭清理员工信息与选中范围 |
| 仓库、旧SKU、店铺基础资料 | 校验和删除确认后作归属检查，读取加序号，旧回包不关闭新窗口；原内容/版本固定，保留编码唯一及CAS边界 |
| 单笔订单审核/取消 | 未确认后不再从已改动表单重新组成请求；原动作、订单、版本、仓库/原因和请求键固定 |
| 订单新建/编辑、文件导入 | 固定原收件资料/明细/版本/请求键；文件导入固定原File、店铺和键。当前未知结果不能通过修改输入改变重试内容 |
| 导入任务 | 重排失败重试不再生成新键/采用新版本；离页旧确认不继续重排，私有原文件读取的迟到结果不下载到另一页面 |

共涉及22个已有Vue组件/页面。生命周期主要以共享提交函数的代表动作测试，原模块参数、金额、权限入口、重试和页面状态回归同时保留；不宣称每个动作×每种浏览器的全部组合都已实测。

## 2. 不混淆接口能力

有持久请求键的接口保持原键、版本和内容重试。旧CAS/唯一编码接口只固定原目标与内容，没有新增服务端原结果缓存；冲突/重复须查询确认，不能推断上一请求失败。

库存状态动作和媒体上传也没有被包装成不存在的原结果重放。已发送请求可能成功，前端离页/忽略回包不是服务器撤销。整个修改没有新增请求字段、修改HTTP契约、变更SQL或放松权限。
