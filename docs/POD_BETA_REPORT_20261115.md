## 具体改动

- `studio/src/GettingStarted.vue`：读取 `/pod/models` 和 `/pod/points` 的实际返回；按整数原值显示正式点数，区分缺图片模型、零点数和读取失败；入口只导航，不提交任务。
- `studio/src/App.vue`、`navigation.ts`：记住分类及 `#runs/<id>`；运行详情刷新/登录后可只读找回，严格限制编号格式，Token 不进入 URL。
- `Templates.vue`：创作端模板导航默认进入官方模板，保留组件原有默认行为及个人/内置预设能力。
- `use-project-run.ts`、`Runs.vue`：网络/可见性恢复只读取，旧列表或详情响应不能覆盖新选择；轮询调度保留序号，避免切回时叠加循环。
- `NodeAction.vue`：运行结果同时核对运行编号、项目、节点及模式；不匹配或 401/403/404 时移除旧正文/图片、禁用重新提交，通知项目清理失效选择；重新核对仍从记录读取。
- `studio/vite.config.ts`：公开示意图绝对 URL 保持站点根路径，解决 Windows 组件测试首次导入 App 时错误转换资源的问题。
- `cmd/podsetup/doctor.go`、`scripts/pod.ps1 -Action doctor`：只读就绪报告，不输出 DSN、密码、主密钥或凭据；warning 不等于失败，也不等于真实供应商验收。
- `scripts/pod-release.ps1`、`deploy/`：编译两个静态端及 Linux API/Worker/podsetup，按白名单装入公共配置/文档/可选 CPU 服务代码，生成逐文件 SHA256；不复制本机数据和凭据。
- 使用说明将当前累计预算更新为 10 元；历史报告数字保留，新增本轮索引与运营文档。

源库没有新增表、修改 001—012、清空缓存、重置账号、改用户权限或提升预算。本轮没有调用真实供应商；测试新建账号及权限仅在隔离副本内。
