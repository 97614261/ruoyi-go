## 1. 模型配置

- 模型目录支持按供应商筛选，显示缺 API Key、缺能力与定价版本、供应商停用、模型停用及未向用户展示。
- 模型管理响应只增加凭据存在性、协议及官方根地址，创作端不增加平台成本或凭据字段。
- 按厂商提供型号示例与能力提示；非千问适配目前只允许文字模型。
- 已有版本仍不可覆盖；配置检查不发模型请求，也不证明真实 Key 有效。

入口：管理端「POD 管理 → 模型管理 → 供应商与凭据 / 模型目录 / 默认模型」。

## 2. 成本与点数

- 成本直接填写人民币元，最多六位小数；BigInt 精确转换成原接口的整数 micros，未修改接口单位和数据库结构。
- 未填写价格会显示行内错误并定位到首个错误字段；免费价格必须明确填 0。
- 点数独立维护，使用非负整数，不和人民币或原模拟额度混算。
- 创作端模型选择显示型号、固定版本及点数单价。
- 执行确认显示服务器报价保存的型号、版本、图片张数和最多预占点数；不以实时目录替换原快照。
- 报价本身不调用模型，执行仍需用户确认；不可用的原模型不偷偷改为默认模型。

## 3. 三套官方入门模板

| 模板 | 用途 | 运行条件 |
|---|---|---|
| 文字生成印花 | 主题文字 → 一张图片 → PNG 印花 | 选可用图片模型，再确认报价 |
| 参考图改图 | 本人参考图与修改要求 → 图片 → PNG | 先选个人素材，再选支持参考图的图片模型 |
| 印花处理与商品预览 | 个人印花 → 基础去白底 → T 恤预览，并分别导出印花与展示图 | 本地步骤，不调用付费图片模型 |

入口：创作端「工作流模板 → 官方模板」。每套均包含操作说明；复制创建独立项目，不自动执行。
需要图片的空槽先由用户选择本人素材，不能直接复制空输入后误认为可运行。
模板不携带环境模型 ID、Key、私人默认图片或运行结果。

## 4. 失败处理

| 情况 | 页面指导 |
|---|---|
| Key 错误、凭据缺失、权限不足 | 提供运行编号，找管理员处理后再决定恢复 |
| 供应商仅免费额度耗尽 | 核对厂商额度；提高本站预算不能解决 |
| 官方型号不可用 | 管理员维护正确版本，回画布选模型重新报价 |
| 输入或参数被拒绝 | 回画布修改、保存后重新报价，不能用恢复旧步骤替代修改 |
| 限流 | 稍后核对原任务，确认失败后手动恢复，不自动重试 |
| 调用结果未知 | 保留预占，只刷新原状态并核对供应商账单，不另建相同任务 |
| 归档待恢复 | 核对或继续下载原结果，不重新生图 |

多个节点中存在待确认调用时优先提示待确认。已有提交结果不明的恢复意图继续按原请求核对，不能被新建议替换成新请求。
供应商响应仍只显示安全本地消息，不回显上游正文、密钥或回执。
