第 3 项权限矩阵已完成本地复核。没有发现本轮需要修改生产后端的新越权问题；增加了测试和文档，没有调整鉴权规则、业务 API、菜单开通、数据库结构或前端业务代码。

- 新增真实 HTTP 矩阵：匿名、平台账号、无 ERP 权限员工逐条验证，分别要求业务码 401/403/403，不能附带业务数据。每轮 567 次入口断言，哨兵 ID 和有效 JSON 空对象不接触既有业务记录。这不是 189 条接口的全部成功用例或所有权限组合覆盖。
- 新增真实订单/部分失败导入任务，先证实原员工可读取任务、结果、完整原文件及有数据的 XLSX，并且原请求重试成功。随后验证跨企业、同店铺同角色的另一提交人、旧 token 撤店铺，以及分别撤 query/import/export 后的访问边界。
- 导入重试使用已经成功的同一正文，避免把版本/状态错误当成权限拒绝。拒绝请求后 attempt 仍为 2、成功订单仍为 1；撤店铺后的列表为空，XLSX 只剩表头；重新授权后同一旧 token 可按当前范围读取文件。原文件逐字节匹配，结果和摘要导出不含合成收件人标记。

现有模块中的仓库/店铺隔离、收货价格分离、财务双范围、附件访问、异步逐单撤权和手工/复核发货权限继续参与完整回归，不被本轮入口测试取代。
