## 实际接口

| 接口 | 附加权限 |
|---|---|
| GET `/pod-admin/bootstrap` | `podAdmin:access` |
| GET `/pod-admin/overview` | `podAdmin:overview:query` |
| GET `/pod-admin/audits` | `podAdmin:audit:list` |
| GET `/pod-admin/audits/:id` | `podAdmin:audit:query` |

所有接口先登录并校验 `podAdmin:access`，再检查具体权限；service 仍复核资格。
成功响应 no-store；沿用统一业务 code、data / rows+total，ID 与金额/字节整数以字符串传输。
日期按北京时间，默认近 7 天、最多 31 天，不能查询未来日期；列表最多 100 条，按时间+唯一 ID 稳定排序，DB 查询有 5 秒超时。

overview 的 creators 字段当前统计启用的个人空间，不是尚未实现的正式用户权益。
存储包含回收站与缩略图；成本由全部调用记录汇总，不从当前节点结果相加，实际账单以供应商为准。
元信息不读取 graph/prompt/output/receipt 或存储键，不回传路径、连接、密钥、哈希或原始回执。

管理入口成功与无管理入口权限的接口尝试同步写 `admin.access`；不能写入审计时拒绝进入。
这不是完整业务写审计：当前没有新增管理业务写接口。具体功能权限拒绝仍沿用公共权限中间件，不宣称所有查询均记审计。
审计 DTO 采用显式字段和有类型快照白名单；列表不读取 before/after JSON，详情不会直接回传数据库 JSON 或 remark。
管理查询未使用采集正文的通用 OperLog。

## 本轮发现并修复

- 概览 DTO 的 States 被 GORM 误识别为关联：显式标为非数据库字段后，真实接口计数检查通过。
- 权限版本 Lua 在 pipeline 使用 Script.Run：冷脚本缓存时 EVALSHA 的 NOSCRIPT 回退发生不了。改为 pipeline EVAL，保持原子 INCR，不整批重放，避免部分成功被重复推进。
- 回归对本次临时员工的权限版本键注入冷缓存故障，不 SCRIPT FLUSH；撤权后的旧会话立即被管理 API 拒绝。
- 原 web 文件上传组件直接 import sortablejs，但 package.json 未声明：补固定 1.15.6 依赖与锁文件；没有换框架或升级其他直接依赖。
- 原后台动态菜单请求失败可能一直等待：补错误传播；退出清理已注册动态路由，避免切换管理账号残留页面路由。
- 原后台密码类请求可能进入重复提交缓存/控制台错误对象：相应请求明确禁正文缓存，移除原始错误打印；POD 管理请求使用独立无正文缓存封装。
- 审计请求开始时将 total 清零，触发 Element Plus 将当前页校正为第一页并再次查询：加载中保留总数，失败隐藏分页，继续使用请求序号拦截旧响应；新筛选仍显式回到第一页。
