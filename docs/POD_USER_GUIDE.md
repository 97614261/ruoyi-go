# POD Studio 使用说明

本地地址：<http://127.0.0.1:5177/>。用 `pod_creator` 登录，密码在本机 `.local/accounts.json`，
照页面填写验证码。启动/停止见 [POD_LOCAL.md](./POD_LOCAL.md)。

## 入口在哪里

登录后默认进入 **首页**：右侧内容区可新建画布、从模板开始或打开最近项目。
左侧 **项目** 查看全部画布，列表每行右侧的 **…** 可重命名、移入回收站；回收站内可恢复。
**素材** 上传和整理图片，**模板** 选择官方、个人或内置流程，**任务与结果** 看任务、图片和批量记录。
右上角显示可用点数，点击点数或头像可看创作资格。手机点左上角菜单打开这些入口，退出登录也在菜单里。

## 切换明暗外观

登录页右上角、工作空间右上角，以及画布顶部都有外观按钮，手机上显示为小图标。
默认深色，点击按钮直接在深色和浅色之间切换；选择记在当前浏览器。
外观切换只改变操作界面，素材、生成图片和导出文件的颜色不受影响。

## 先做一张

打开 **首页 → 制作商品图**，可以复用已有商品素材包。要成套出图，勾选需要的白底主图、场景图、45° 展示图、侧面图或细节特写，核对逐项点数后确认生成。补做完成后，可从该用途的 **挑选候选图** 手动换定稿。每种已选用途各确定一张，再点 **下载定稿 ZIP**。

做印花或样机时，在同一入口选 **整理印花** 或 **T 恤样机**，确认选的是印花原图，再创建画布。可在画布调整印刷规格、衣服颜色和图案位置，运行后从结果下载。

首次登录可在 **首页 → 使用帮助** 查看点数、可选模型和快速上手。
也可以直接点 **首页 → 从模板开始**，默认打开官方模板，选“印花处理与商品预览”，填名称、选择自己的图片，再点“复制并打开画布”。
文字生图/参考图改图需要可用图片模型；没有模型时页面会提示联系管理员，已有图片仍能本地处理。

也可以使用原有内置预设：

1. **模板 → 内置预设 → 已有印花做 T 恤**：创建项目并打开。
2. 在画布的**图片输入**点“选择或上传图片”，选自己的 PNG/JPEG 图片。需要透明底时优先 PNG。
3. 点**图片处理 → 调整参数**，选择裁剪、尺寸、去背景或放大。纯色去背景适合干净底色；AI 抠图/放大需要本机 CPU 服务。
4. 点**商品预览 → 调整印花布局**，拖动图案、调整大小、选择衣服正反面和底色；也可直接居中。
5. 等顶部显示**已保存**，执行整条工作流。在节点或运行详情看进度。
6. 成功后分别下载**印花**和**商品展示图**。印花是实际图案，展示图是穿在 T 恤上的二维示意。

像素太小时会提示 DPI 低。放大和修改 DPI 标签不保证印刷质量，最终按生产商要求检查。

## 想让 AI 画图

在画布加入**文本输入 → AI 生图**并连线。文字里说明画什么、风格、颜色和背景；
生图卡片先选已授权模型，再选比例、数量；点“立即生成”后自动核价并提交，不再勾选或二次确认。
模型下方显示单价，例如“每张 25 点”：生成 1 张为 25 点，2 张为 50 点；上游有其他 AI 节点时另计。
文本输入上的“AI 润色”会先给结果，确认后才替换原文。

**当前已切换为模型目录模式。2026-11-15 本机已验证 Pro 单图生成，并设为默认图片模型；文字仍默认低价 Flash，也可选新增的千问 3.8 / 百炼 DeepSeek。**
两个原测试账号已授权。Omni 当前只用于文字，图片翻译尚未开放；没有模型时请管理员核对配置、授权和点数。
免费额度按具体型号计算，截图不是实时余额；到期或用尽后的失败不能靠反复重试解决。
部署者需要在百炼核对开通和付费设置；本项目不会自动开付费。
已有图片的本地处理、T 恤预览、模板和批量仍可使用。

## 最后的导出节点

**结果导出**把上游图片按文件名、格式（如 PNG）和印花/展示图参数保存，导出本身不扣模型点数。
只想拿已有结果，直接点结果旁的**下载**，不会重新调用模型。
节点的**生成导出文件**会执行该节点和所需上游；上游含 AI 生图时会重新生成并计费。

生成或处理完，点击节点上的缩略图可看原图。关闭结果弹窗或修改参数后，还可从 **画布右上角 → 结果** 找以前的图、切换运行记录并下载。历史图片会标明画布版本；查看不会再次生成或扣点。离开画布后，从左侧 **任务与结果** 也可以按运行记录找图。

如果提交时提示点数不足，本次没创建新任务。页面会尽量列出这次需要的点数和当前余额；可以减少张数、换低价模型，或联系管理员补点，不影响查看旧图。

## 接着处理之前的结果

画布顶部 **执行流程 → 使用哪次生成结果**，选择同画布版本、同执行模式的成功记录，
再点 **仅执行选中节点**，可以接着处理上游已有结果。缺少合适的结果时会拒绝，不会自动重做上游。
这项选择不影响 **执行整条流程**；整条流程仍会重新执行。

## 保存成自己的模板

画布顶部点**保存为模板**，填写名称。
以后从**模板 → 我的模板 → 使用模板**，选择版本、换本次文字或图片，再创建项目。
手机上先填输入，版本选择和可展开的“流程预览”“模板说明”在下面；右上角关闭详情。
新项目独立，改模板不影响旧项目；使用模板不会自动执行或收费。

## 手机和平板怎么操作

- 电脑、手机画布底部都保留 **节点、模板、撤销、参数、更多**。点“节点”再点卡片添加，不必拖入画布。
- 选中节点后点 **参数**，或点节点标题上的设置按钮；面板里可以滚动，点关闭按钮或面板外空白处收起。
- **更多 → 连线**：依次选来源节点、输出端口、目标节点、输入端口，再点“添加连线”，适合触屏。
- 预设、提示词灵感、重做、复制、删除和缩略图也在 **更多** 里。
- 连线上的细光段表示从上游到下游的方向，选中节点会突出相关线路；它不代表任务正在执行。**更多 → 动效** 可开关，浏览器会记住选择；系统设置减少动态效果时自动停用。
- 拖动画布空白处平移，双指缩放；也可以使用左下角的放大、缩小、适应画布按钮。拖动节点标题移动节点。
- 保存、保存为模板、执行流程在顶部。手机横屏会压缩顶栏，平板保留侧边工具和参数面板。

## 一次做多份

1. 先把单份流程跑通并保存为个人模板。
2. **模板 → 我的模板 → 使用模板 → 批量制作**，选择版本。
3. 每一行是一份输入，可“复制输入”再逐份换文字/图片，每批最多 10 份。
4. 点**核对份数与费用**，确认后点**开始批量**。改了输入就要重新核对。
5. **任务与结果 → 批量**查看每份结果；可以打开独立项目或运行详情。
6. 点**下载已归档图片 ZIP**，按每份的 `print` 印花、`mockup` 展示图分类。

“已全部派发”只是都已交给执行队列，还要看每份是否成功。
“停止待派发项”只停尚未派发的份数；已派发去运行详情取消。
ZIP 会包含成功处理/预览图片，不限于最后导出的成品；最多 100 图、100 MiB，大结果请分别下载。

## 出问题看哪里

| 情况 | 怎么处理 |
|---|---|
| 保存冲突 | 先下载草稿或另存项目，再重新加载；别直接丢掉修改 |
| 提交超时、结果不明 | 点“重试原提交/原批次提交”，先确认旧请求；不要另开一批重复做 |
| 某份失败 | 打开该份运行看原因；确认原因解决后再显式恢复，可能重新收费 |
| 待确认 | 保留记录，联系部署者核对供应商；不要反复生成或删记录 |
| AI 图片服务失败 | 检查本机 CPU 服务；不会自动降级为普通处理 |
| 素材不能删除 | 仍被项目、运行、模板历史或批次引用；回收站也保留引用 |
| 看费用 | 正式模式点击右上角点数看余额和流水；历史任务可查看本次预占和实际扣点。测试额度不能抵正式点数 |

当前 10 元是全实例累计估算上限，不是每人余额。自己的统计不能用来推算全局余额，实际费用以百炼账单为准。
项目参数改完要重新执行才有新结果；刷新只恢复查看，不会自动再次调用模型。
运行详情的链接会记住所选任务，刷新或重新登录后仍可核对原记录；网络恢复和回到页面也只读取状态，不自动再次制作。

## 正式点数怎么扣

点击生成、润色或执行后，系统自动取得服务端报价并提交预占，不再弹点数确认框；确认用量后结算，没用完的自动释放。
本地图片处理不扣模型点数；流程中的上游 AI 重新执行仍可能扣点。
批量保留份数预览，点“开始批量”后自动核价并预占整批；停止只释放没派发的份额。
点击“恢复失败步骤”后自动获取新报价，只重做失败步骤。报价失败、过期或余额不足会阻止提交。
“待确认”先保留预占，联系管理员核对；别换新请求反复生成。

## 使用官方模板

**模板 → 官方模板 → 查看并使用**。填写本次项目名称和文字；图片可以保留模板默认图，也可以勾选替换并从“我的素材”选择。
列表只展示简介，完整步骤在详情的 **使用说明** 中展开查看；画布底部或侧边的 **模板** 按钮也能打开同一套模板库。
点**复制并打开画布**后，得到自己的项目。模板图会复制成个人素材，占个人存储；这一步不执行模型、不扣生成点数。
管理员更新或下架模板，不影响已有项目。复制超时显示“继续原操作”时，先继续这一份，不要换请求再建。

## 后台管理位置

管理员使用 `http://127.0.0.1:5178`，普通用户使用创作端 `5177`。

| 位置 | 怎么用 |
|---|---|
| POD 管理 → 任务中心 → 运行任务 | 按日期、用户 ID、模型 ID、状态查询；详情看节点进度。“取消运行”停止未执行步骤，已提交的继续核对 |
| 任务中心 → 批量派发 | “停止待派发”仅停止没派发的项；已派发项到运行任务里单独取消 |
| 任务中心 → 私有访问授权 | 有权限的管理员填写操作员、资源所有者、单个运行/素材、用途与到期时间；最多 24 小时。读取会留审计，撤销影响之后的读取 |
| POD 管理 → 用量统计 | 查询最多 31 天的用户/模型调用次数、估算成本与调用点数；完整账户余额在创作者详情看 |
| POD 管理 → 官方模板 → 平台素材 | 上传有权提供给用户的图片，并写清使用权说明；这是平台素材，与用户私有素材分开 |
| 官方模板 → 新建模板 | 选起始流程，填默认文字、平台图片、比例与张数；模型可留空，让用户复制后选择。保存得到草稿 |
| 官方模板 → 版本与发布 | 明确选择一个版本发布。修改流程用“新增版本”，不会改掉原版本；下架后新用户不能再复制 |

后台列表看不到用户正文、原图或结果。即使是超级管理员，读取用户内容也要有该资源的有效授权；运行授权不会顺带授权图片。
操作超时先点“核对原操作”；需要重填时沿用原编号、原内容和原原因，避免重复创建或授权。不要把点数、成本和旧测试额度混为一笔钱。
