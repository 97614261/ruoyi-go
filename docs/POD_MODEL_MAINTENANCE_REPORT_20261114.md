## 4. 后台怎么维护

1. 用 admin 登录管理端，进入「POD 管理 → 模型管理 → 供应商与凭据」。选对应厂商，点「配置 / 轮换凭据」，填该厂商自己的 API Key；Key 加密保存，不回显。
2. 进入「模型目录」，找到对应草稿，点「保存新版本」。填写官方模型 ID、能力、超时、成本和点数。其他厂商文字接口只允许固定官方根，不接受中转站；保存错误厂商的模型 ID 会拒绝。
3. 本轮费用规则仅接受人民币 CNY micros。外币价格先明确换算口径再配置；不要用零价占位，不把平台点数当供应商费用。
4. 凭据和版本完整后先做「配置检查」，再启用供应商和模型。配置检查不发模型请求，不能证明 Key 有效。实际联通验证应单独授权、有预算、只提交一次。
5. 进入「创作者管理 → 模型范围」，明确给用户授权。只有供应商与模型启用、可见、有版本且用户获授权的模型才会显示在创作端。
6. 进入「默认模型」选择文字/图片默认项。创作端在文字或图片生成节点的模型选择器切换型号，再按报价确认执行。

千问图片恢复：先在百炼控制台核实当前 Key 所属空间、模型权限和额度/仅免费限制；确认愿意承担供应商收费后，先对一个图片型号做有界验收，再决定启用范围和图片默认值。
本次没有再次调用图片来证明其他三个型号可用。缺其他厂商 Key 时保持停用即可，不需要把 Key 发到聊天里。

原本地 YAML Key 保留以兼容旧配置，新的 managed 请求读取目录中的加密凭据，不会在缺其他厂商 Key 时借用千问 Key。
主密钥位于独立 keyring，需单独受限备份，普通 bundle 不包含它。
