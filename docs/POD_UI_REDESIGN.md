# 创作端第二版视觉方案

日期：2026-11-12。范围为 studio 创作端，重点是项目画布，同时统一项目列表、登录、素材和运行的视觉语言。

> 本文保留首次改版快照。后续节点内润色、竖向工具、生成与创作库交互见 [节点交互记录](./POD_NODE_INTERACTIONS_20261112.md)。

## 设计判断

这是给 POD 创作者使用的节点工作台。参考小龙的无限画布、节点连线和就近操作，不复制其品牌、私有实现或素材。
此前附图是接口说明而非画布截图；本轮另核对了参考站公开页面及画布样式。浏览器连接宿主不可用，不能声称已逐屏比对参考站。

当前问题是左右面板挤占画布、节点之间只有文字区别、字号过小、项目封面雷同，以及部分文案落后于实际能力。
本轮把辨识度集中在节点本身：图文分型、彩色类型标记、清晰端口与结果区域；其余工具保持克制。

## 变量

| 角色 | 值 | 用法 |
|---|---|---|
| 画布 | #eef0f4 | 银灰点阵工作面 |
| 面板 | #ffffff | 悬浮工具、节点、表单 |
| 正文 | #242837 | 主要内容 |
| 次要文字 | #626b7b | 说明、状态 |
| 边界 | #d9dee8 | 节点与面板层级 |
| 主色 | #3156d3 | 品牌、选中、主要动作 |

保留本地 Manrope Variable，中文使用已有中文字体回退；不新增在线字体依赖。
正文 13—14px，次要说明不低于 12px；小型编号只用于真实节点标识或快捷键，不添加装饰性序号。
圆角按角色区分：按钮/输入 8px，节点/浮动面板 14px；阴影只用于真实悬浮层级。
节点语义色用于识别文本、图片、生成、处理；选中状态统一主蓝，并保留文字与图标，避免仅凭颜色识别。

## 布局

```text
项目列表：品牌 + 紧凑页签                         工作空间 / 账号
          标题 / 简短说明                        新建项目
          新建入口与已有项目封面、更新时间、操作

画布：返回 / 项目名 / 保存状态                   模式 / 保存 / 执行
      ┌节点工具┐                                  ┌节点参数┐
      │搜索    │       文本 ─── 生成 ─── 图片      │就近编辑│
      │紧凑列表│                                  │可收起  │
      └────────┘                                  └────────┘
      缩放控件            选择 / 撤销 / 复制等工具       画布信息
```

画布占满编辑区，两侧面板覆盖在工作面上，不再压缩 Vue Flow 的宽度。参数与执行面板共用右侧位置。
小屏侧面板互斥打开，按钮保留可达的触控面积；执行入口不隐藏。图库与运行继续使用现有功能，不增后台菜单。

## 自查与实现边界

通用设计搜索最初返回营销页建议，与工作台不符，未使用其 Hero/CTA 布局。更窄查询匹配到视觉构建工作区，
仅采纳中性画布、类型色和紧凑工具的原则；颜色、布局和节点结构按本产品单独设计。
不依赖更换配色制造区别，也不增加无功能的按钮、假模板、假生成图或假统计。
保留权限、保存/恢复、运行确认、费用提示、素材鉴权、键盘连线和 reduced-motion 边界。
验证记录见下节；真实账号业务验收与供应商验收不由本轮替身截图替代。

## 已实现改动

- 全宽点阵画布、紧凑顶栏和底部浮动编辑工具；缩略图按需打开。
- 左侧节点工具支持搜索，文本、图片、生成、处理、预览与输出有类型图标。
- 文本节点直接编辑要求；图片节点显示真实素材；生成节点显示比例、数量和真实运行结果，未执行时保留明确占位说明。
- 参数和执行面板互斥；桌面选中节点被遮挡时平移视角，手机同一时刻只打开一个侧面板。
- 项目列表改为紧凑流程封面及新建入口，登录、素材和运行统一字体、颜色与表单样式。
- 手机保留保存与执行入口，底部编辑和缩放工具分层放置，修正登录标题断行、图片裁切与横屏高度。

画布验收中发现原来的常驻网格吸附会把旧图非网格坐标改成整格坐标，进而触发自动保存。
现改为仅拖动时吸附；打开、选择、平移与切换面板不得改动图数据，增加了对应回归用例。
