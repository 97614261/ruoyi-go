# 图片制作阶段（2026-11-12）

范围：基础处理与导出、去背景与高清放大、T 恤二维预览。复用现有私有素材、运行快照、租约与归档表；不修改已安装迁移，不另建管理后台。

实施顺序：

1. 有界本地执行器：旋转、裁剪、等比缩放、PNG/JPEG 导出；保留原图、透明通道、来源和运行引用。
2. 纯色背景移除与普通插值放大；另接自托管 CPU AI 服务（rembg / FSRCNN），明确区别普通处理与 AI 推理，不调用付费供应商。
3. 自绘 T 恤正反面预设、限制印刷区域、位置/缩放/底色可保存；印花与商品展示图分别输出，检查有效 DPI。
4. 创作端复用节点与参数面板，补齐执行、原图预览、下载及可视化印花拖动。
5. 算法、参数、接口隔离、任务恢复与前端回归；更新当前计划和操作说明。真实模型安装和推理结果单独记录，不把接口模拟当成真实推理。

接口继续使用 `/pod/runs` 与 `/pod/assets`：列表保留既有分页上限；查询复用主键、空间与归档索引；文件逐项处理但不在业务层查库；存储、调用与任务均有 context/超时；沿用 POD 功能权限和空间授权；错误走统一响应且不暴露文件路径、密钥；新增输出元数据采用 camelCase。

视觉：延续现有浅色节点画布、Manrope 字体与蓝色主操作。节点只放常用动作，细项留右侧；T 恤和印花是视觉主体，不另加后台菜单。移动端保留参数输入作为拖动替代。

1—3 已实现，自动化、真实 CPU 链路及组件交互已验证；完整登录浏览器与复杂质量验收仍待补。
