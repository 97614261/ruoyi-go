# Studio 外观与节点样式修复

日期：2026-11-17。本报告记录本轮修改与验收，当前操作说明见 [使用说明](./POD_USER_GUIDE.md)。

## 修改

| 内容 | 当前行为 |
|---|---|
| 历史上游结果选择 | 改为“使用哪次生成结果”，空项为“不复用之前的结果”；说明只影响“仅执行选中节点”，复用同画布版本、同模式的成功上游 |
| 节点右下角 | 末尾端口区和运行结果底栏跟随节点圆角，不再用方形背景盖住外框；保留外部连接点，不裁切连线端口 |
| 模型选择 | 生图节点模型下拉框占满内容区，长名称按控件宽度显示 |
| 外观切换 | 登录、工作空间、画布提供“跟随系统 / 浅色 / 深色”，默认跟随系统；手动选择保存到当前浏览器，并同步同源标签页 |
| 暗色范围 | 画布、节点、工具、模板、运行面板、参数面板、表单及弹窗；素材图片与导出内容本身不变色 |
| 窄屏 | 手机保留图标入口；横屏顶部操作占独立一行，避免新增外观按钮挤压操作区 |

实现位于 `studio/src/theme.ts`、`ThemeSwitch.vue`、`theme.css`。`studio/public/theme-init.js` 在应用加载前应用同一偏好，减少首次加载颜色闪变。
浏览器无法使用本地存储时，当前页面仍能手动切换；不支持系统偏好检测时默认浅色。

## 验证

| 检查 | 结果 |
|---|---|
| `cd studio; pnpm test` | 22 个测试文件、170 项通过 |
| `cd studio; pnpm build` | TypeScript 检查与生产构建通过；保留既有主包超过 500 kB 的提示 |
| 主题逻辑 | 自动覆盖系统变化、手动覆盖、刷新恢复、标签页同步、非法/受限存储、旧版媒体监听与启动脚本一致性 |
| 切换交互 | 自动覆盖选择后收起并恢复焦点、Escape、点击外部关闭和选中状态 |
| 文案回归 | 组件测试核对新标签、解释文字及原 baseRunId 提交路径 |
| 本地页面 | 检查登录、工作空间、画布、模板库、预设/模板详情弹窗、参数面板和执行面板的暗色显示 |
| 浏览器尺寸 | 1280×720、768×1024、375×812、844×390；检查入口、下拉菜单、面板和横屏按钮布局 |
| 刷新 | 手动深色保留；验收结束恢复“跟随系统”，再次刷新仍保留该模式 |

系统外观变化由自动测试触发媒体事件验证，没有更改 Windows 本机主题；响应式检查为桌面浏览器视口测试，不等于安卓/iOS 真机验收。

本轮未调用真实模型，未改动后端、数据库结构、价格、预算或账号权限。仅在既有专用验收项目 4564 增加一个未连线的生图节点并调整位置，未执行它，未修改用户其他作品。
