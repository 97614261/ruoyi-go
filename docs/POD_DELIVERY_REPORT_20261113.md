## 千问真实样本及费用

此前真实样本已覆盖短文字、润色、单参考图、五种比例和两张输出，历史证据保持有效。
本轮试跑 **3 张输出 + 2 张参考图**（运行 2157）和 **4 张输出 + 3 张参考图**（运行 2161）均失败；
后者显式做过一次诊断恢复，仍得到供应商 **HTTP 403 / AllocationQuota.FreeTierOnly**。

原因是免费额度耗尽且供应商配置为仅免费调用。没有证据表明是多图参数不支持，
本站 5 元预算也不会打开百炼付费。未去供应商控制台启用付费、充值、换模型或改地域。
3/4 张及多参考的**成功验收未通过**，控制台账单未核对。

代码新增本地错误 `providerFreeQuotaExhausted`，只显示固定安全提示；
仅明确的 403 和精确错误码匹配才归类，其他 403 保持拒绝、500 保持待确认。
测试验证无原始回执泄漏、无自动重试及零新增费用；供应商结果未知时仍保留预占。

本轮前后累计估算均为 **1.000385 元**，新增估算 **0 元**；
最终调用记录 16 条、未结预占 0、排队/运行/待确认任务 0。实例累计预算仍为 **5 元**，并发全为 1。

| 操作 | 输入 → 输出 | 墙钟时间 | CPU 时间 | 单核口径平均 CPU | RSS 基线 / 采样峰值 |

| u2netp 抠图 | 1024×1024 → 1024×1024 | 0.496s | 0.844s | 170.0% | 106.4 / 400.1 MiB |
