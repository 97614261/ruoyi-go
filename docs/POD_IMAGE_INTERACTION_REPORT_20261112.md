## 1. 改了什么

| 位置 | 当前行为 |
|---|---|
| 图片处理 → 调整参数 → 裁剪 | 原图框选、框内移动、四角调整；重新框选、恢复全图；保留数字输入 |
| 裁剪预览 | 先旋转再裁剪，显示旋转后尺寸与实际保留像素；方向键移动，Shift 加快 |
| 裁剪/印花手势 | 过程中只更新本地预览，松手一次保存；Escape、取消、换图、禁用或卸载丢弃未完成手势 |
| 裁剪数字 | 校验起点与保留宽高的组合范围，非法输入不写回项目；可用全图复位修正旧配置 |
| 图片处理结果 → 对比 | 画布、节点执行弹窗及运行详情均可打开；读取结果的实际 parentAssetId |
| 对比弹窗 | 并排、只看处理前/后；棋盘底；适应、100%/200%/400% 原图像素检查；窄屏单列 |
| T 恤 → 调整印花布局 | 水平/垂直/全部居中、布局复位；显示位置比例和 1000 × 1200 示意画布的像素坐标 |
| 项目运行状态 | 当前标签页记住所选运行，刷新后鉴权读取；非终态轮询，明确显示上次版本、CPU 处理中与失败原因 |

布局复位为 `printX=.5, printY=.4, printScale=.6`；全部居中为 `.5/.5`。
复位保留正反面、底色及其他配置，坐标提示不是生产印刷毫米规格。
多图继续共用相同比例裁剪区域；此轮没有增加逐图独立裁剪或批量入口。

## 2. 一致性与资源边界

- 本轮没有新增 HTTP 接口、节点配置字段、数据库表或迁移，schema 保持 001—006；没有修改 `web/`。
- 项目只保存已有比例字段；多字段修改原子应用到画布，沿用草稿自动保存、版本冲突和撤销/重做。
- 前端裁剪提示使用两端分别向下取整，不能用比例宽度直接乘原宽；与 Go 旋转后的实际裁剪结果核对。
- T 恤预览和 Go 合成共享同一印花区域与舍入规则；本轮只增加后端测试，没有修改生产渲染算法。
- 对比图片来自本次结果的直接输入，不拿当前画布新输入冒充历史原图；缺失或无权访问时显示错误，可重新读取。
- 原图请求仍带 Authorization 请求头，Token 不进入 URL。换图和卸载释放对象 URL，迟到响应不得重新打开已过期预览。
- 运行编号按账号/空间/项目保存在 sessionStorage，不能跨浏览器恢复；不保存凭据和图片内容。
- 恢复仅使用 GET，不能重新提交、自动恢复失败任务或重发未知调用；运行面板打开时暂停编辑器的重复轮询。
- 旧请求不能覆盖新选择；401/403/404 清除不可访问的运行及旧结果；卸载停止后续轮询。
- 状态明确标记“上次执行/来源版本”，CPU 标识读取运行快照的方法，不根据刚修改但未执行的参数猜测。
