## 1. 最终产品边界

| 部分 | 使用者 | 职责 |
|---|---|---|
| `studio/` 创作端 | 普通创作者 | 登录、项目、素材、模板、模型选择、制作、下载、本人点数和账号设置 |
| `web/` 管理端 | 平台管理员、受限运营 | 用户开通、权益、供应商/模型、官方模板、任务、成本、点数流水和运行状态 |
| Go API + Worker | 两端共用 | 后端鉴权、个人空间隔离、可靠队列、执行、计费和归档 |
| MySQL / 独立 Redis / 私有存储 / 可选 CPU 服务 | 服务端 | 沿用当前隔离配置和执行机制，不增加微服务或企业多租户 |

两端可部署在同一服务器、不同域名或路径。Vite 代理仅用于开发；生产静态代理、TLS 和目标机器另验。
两端各自管理浏览器会话；共用账号体系不表示普通用户可以登录后台或调用管理接口。
后台入口加载前检查 `podAdmin:access`，服务端每条接口仍检查具体权限。

第一版由管理员开通用户、人工发放正式点数；暂不做自助注册、充值/订阅/支付、企业协作、模板市场。
自助注册继续保持当前关闭状态，POD 初始化接口不能自行恢复被撤销的资格。

管理端保留六个入口：运营概览、创作者管理、模型管理、任务中心、官方模板、用量统计。
当前模型页用模型目录/供应商与凭据/默认模型三个 Tab；用户资源限制在创作者管理；任务页用运行/批次 Tab；创作者详情用权益与存储/模型范围/点数与流水 Tab。

## 3. 供应商、模型和版本

供应商是账号/地域/接口来源；模型是一个可选能力。一个供应商可挂多个文字和图片模型，
不同供应商也可提供相同官方模型。模型目录不是任意 HTTP 请求配置器。

第一轮先实现千问已有协议的多模型配置。基线为 qwen-flash、qwen-image-2.1-turbo；
第二个同类型模型在实现阶段核对官方规格、适配和定向测试后启用，不凭模型名相似推断兼容。
DeepSeek、OpenAI 等留出适配器注册位置，不在只有配置记录时宣称已经接通。

每个模型有稳定 modelId 和不可变 modelVersionId。版本包含：

- 供应商 ID、适配器及适配器版本、官方模型 ID、允许的官方 endpoint/地域快照。
- 文字/图片类型、输入和输出限制、合法比例/尺寸组合、输出张数、参考图数量等有类型的能力规格。
- 请求超时、输出 Token 上限、成本估算规则、用户点数规则及其版本；缺失计量规则不能发布。
- 展示说明和必要的质量提示。后台不接受任意请求模板、脚本、Header 或透传 JSON 绕过适配器。

model 当前版本指针可更新，旧版本不可覆盖。模型/供应商/版本只归档或停用，有历史引用时不物理删除。
文字、生图分别设置一个平台默认；只有处于 enabled、配置完整、适配器支持、用户有授权的模型可执行。
用户无权使用平台默认时要求自行选择，不静默替换为更贵或不同模型。

生图参数应按模型版本定义的合法组合校验，而不是允许任意 width/height。
旧图的 ratio/count 仍可读；不兼容新模型的参数由用户确认调整后保存。

### 凭据与启停

密钥使用 AES-256-GCM 加密，带随机 nonce、keyId 和版本；AAD 绑定供应商/凭据版本/用途。
主密钥从服务端专用环境变量/密钥文件读取，不与 JWT 共用、不存数据库、不入 Git。
未配置主密钥时拒绝持久化凭据；不降级明文。响应只返回 credentialConfigured、版本和状态，不回显密文或明文。

凭据轮换新增版本，逻辑供应商不可借轮换换成另一个计费主体。尚未提交的新调用领取当前有效凭据版本；
已提交调用固定实际凭据版本，只核对或归档，不因换 Key 再次 Submit。
旧凭据撤销后也保留调用归属；确需查单而旧凭据不可用时提示待核对，不用另一个账号伪装原调用。

供应商/模型停用同时作用于新提交和尚未发出的新调用；已发出调用允许继续确认和结算。
变更在领取事务中重新核对，缓存失效时拒绝新调用，不能靠过期缓存放行。
endpoint 更改产生模型新版本，旧版本使用旧 endpoint；生产 endpoint 采用适配器允许的官方 HTTPS 域名，禁内网、代理和重定向。

## 4. 创作者资格与资源限制

复用 sys_user、sys_role、sys_user_role 和当前个人空间，不复制账号表。
POD 创作资格采用独立 policy，不把运营人员的其他系统权限一起停掉。

| 资格状态 | 访问行为 |
|---|---|
| active 且未到期 | 按权益编辑、上传、提交、读取和下载 |
| 到期 | 只读本人项目、历史结果、点数和下载；不新增任务、上传或写画布 |
| suspended | 只显示本人资格/点数说明和账号设置，阻止 POD 私有内容读写及新任务 |
| sys_user 停用/删除 | 沿用系统账号禁用和会话失效机制 |

资格在 HTTP、批次派发、节点领取、真正外部 Submit 前再次校验；已提交调用的核对/归档/结算不因资格变化中断。
恢复资格是显式管理操作，不能由 /pod/workspace 自动恢复；新建用户默认没有点数，也不自动授权所有模型。

权益字段：validUntil、maxConcurrentNodes、maxPendingRuns、maxDailySubmissions、maxStorageBytes、allowedModels。
平台配置是硬上限，用户设置只能收紧，不能让用户或模型的较大值突破实例总并发/预算/上传边界。
到期使用数据库时间，业务日期采用 Asia/Shanghai。

每日提交额度按已接受的单次 run/显式恢复计数，批次按份数计数；同 requestId 不重复计数，延迟派发不再计数。
取消和失败不返还当日提交次数，避免刷任务；点数释放另按实际调用状态处理。
当前每用户并发门和批次 checked_at 重试轮转已生效；记录 last_dispatched_at 供后续跨用户调度使用，严格公平调度及容量评估留待执行集成/验收，不作为本步已实现承诺。

资格和资源上限必须为正且不超过服务端硬上限，0 不解释为无限；禁用能力用明确的状态/授权控制。
validUntil 为空表示无到期日，非空必须是合法 Shanghai 时间，边界为 DB 当前时间 >= validUntil 即到期。
额度下调不删除文件、不收回在途 held；若现有使用已超新上限，阻止新增并给出明确说明。

存储限制统计原图、缩略图、派生图和回收站文件，生成结果同样占用。
写文件前按有界输出预留空间，文件记录提交后转为已用；并发上传/归档共用空间锁及幂等空间预留。
中断/孤立文件先精确核对，不能仅凭预留超时就释放或删除。历史引用仍受保护，本轮不开发永久清理。

## 5. 平台成本、正式点数、测试额度

三种口径独立：

| 口径 | 用途 | 权威记录 |
|---|---|---|
| 供应商估算成本 | 平台成本和累计预算兜底，micros 整数，实际账单另核对 | pod_provider_call 及模型成本版本 |
| 用户正式点数 | 用户获发和消耗的产品额度，整数点数，不宣称人民币余额 | 新 points_account/event/call_billing |
| 模拟测试单位 | 开发场景的模拟执行 | 原 pod_credit_account/event，原样保留 |

第一版点数定价：文字按输入/输出 Token 费率，图片按输出张数及受支持规格费率；
整次调用合计后向上取整到整数点，不按每 Token 单独取整；价格使用整数分子和明确分母，禁 float 金额。
本地图片处理/预览/导出第一版不扣正式点数，但仍受资格、CPU、队列和存储限制。
后台可独立设置点数价格和供应商成本，创作者新界面显示点数，管理端看成本。
既有 /pod/usage 响应保持兼容，不删改历史成本字段；新用户点数页使用新接口。

新 managed 请求先取得服务器报价，再确认创建。报价有效 10 分钟、本人待使用报价最多 20 个；
固定来源 revision/内容摘要、执行范围、模型版本、定价和权限版本。报价不预留点数或供应商预算。
创建事务重新核对资格、版本、额度和幂等；过期/价格变更返回 409 要求重新报价，不悄悄换价。

单次运行创建时预占整条所需正式点数；批次创建时预占全批正式点数，待派发停止项释放其未分配部分。
每项分配独立持有份额，派发转移不重复预占。供应商成本仍逐调用预占，平台预算不足可能部分成功。
未知提交重试原 requestId，先查已提交结果再处理报价过期，不能因为旧报价过期重复扣点。

每次外部调用提交前，以 submissionKey 同事务绑定正式点数份额、成本预占和调用意图，提交后才允许网络 I/O。
确认后按实际可确认用量结算一次；没有提交的取消部分释放，已知拒绝按确认结果结算，
结果未知保留相应份额。下载/归档重试不再收费，原调用返回部分图片时按确认用量处理。
显式恢复的新增调用需要新的报价和增量预占，已成功节点复用，不重新扣旧调用。
同一 managed run 的恢复沿用该 run 固定的模型版本和定价；恢复报价只计算新增调用份额。
需要换模型或采用新价格时创建新 run 并重新确认，不能借 retry 改写旧绑定。

预占上界必须由适配器根据输入/输出硬限制计算。供应商报告超过上界时保存实际用量和平台估算成本、报警并阻止该模型新调用；
用户本次扣点最多为已确认预占额，超出由平台承担，不制造负余额，也不能丢弃回执假装免费。
新增人工发放/扣减只影响 available，扣减不得动 held 或超过 available；必须有原因、requestId 和同事务审计。
没有直接 setBalance、清账重置、未知调用退款或自动重发入口。

## 6. 任务、隐私和模板

管理任务列表默认只给元信息、状态、时间和统计，不带提示词、图 JSON、原图、结果或供应商回执。
查看私有内容必须同时满足显式管理权限和资源范围授权；即使超级管理员也查 grant，不以 *:*:* 代替。
grant 只针对指定 run/asset，最长 24 小时，写明原因；读取正文和二进制下载前同步落审计。
后台不能冒充 creator 调现有 owner 接口，不改变原个人空间鉴权。

第一版管理操作只提供取消运行/停止待派发，不替用户发起收费恢复；创作者自行确认恢复。
未知结果只列待核对、关联安全标识；供应商原始响应、密钥、签名 URL 不进入管理 DTO。

官方模板与个人模板是两种资源。官方模板使用平台上传且有使用权的独立公共素材，
后台不把用户私人模板/素材改一个 public 标记就发布。
发布版本不可变，下架只阻止新使用；用户使用时将所需官方素材复制为本人私有素材、预留其存储并创建独立项目。
复制按文件上限、操作幂等记录和短事务分阶段恢复；不跨文件 I/O 持有长数据库事务。
模型下架或无授权时提示替换并重新报价，不暗中换模型；模板使用本身不执行或扣模型点数。
