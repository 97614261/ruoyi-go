# 本轮：资料下载中心、行业模板与页面预设

承接已验收v15。SMTP、多语言、自定义表单、通用内容迁移和运维面板不做。

1. 下载中心：独立分类/文件/资源/不可变修订，最多20MiB，PDF/DOCX/XLSX/TXT/ZIP；流式接入、有界校验、私有随机文件名、强制附件下载。资源草稿与公开指针分离，独立发布权限；本期不扩充原内容四类审核策略，界面明确说明这一边界。分类停用、资源下架/删除实时阻断公开访问；历史引用阻止物理文件删除。
2. 行业预设：制造工程、企业服务、资讯内容三套内置信任方案，复用三套已注册主题。样式示意预览、变更清单；可选择生成关于/服务/联系页面草稿，精确前缀避免覆盖。应用绑定当前外观版本、计划摘要与幂等请求ID，同一事务创建新页面并更新外观草稿，不改线上、不改旧内容，仍须原内容/外观审核和发布。
3. v16显式增加5张cms表（58表）及6120—6131菜单，无旧表/sys结构修改和自动角色授权；升级前完整备份。
4. 全量回归、越权/版本/同名/幂等/草稿隔离、文件类型/大小/引用、页面/恢复验收；补大白话使用说明及后续路线。
