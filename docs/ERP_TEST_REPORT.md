### 实际发现及修改

- 仓库授权原先在确认框结束后才设saving，连点可产生两次确认。现将确认阶段纳入busy窗口，并固定确认时的员工ID、版本与仓库集合；取消/失败均在finally释放。
- 关闭后重新打开授权弹窗，旧员工范围请求可能回填。现新开窗口推进请求代数，响应还必须匹配当前员工且窗口仍打开。
- 原多租户回归直接操作demo/demo-b，依赖真实密码且会切换所有者/企业状态。改为新建专用验收企业，测试结束停用并保留数据，平台现有密码只在内存核验，不为测试重置。
- 修正历史测试假通过风险：外部门角色关系验证改用实际本企业ID；跨企业所有者变更带有效当前version；目标企业直接按ID读取，不能因未出现在分页首屏而跳过负例。
- 连续回归触发了正常的60次/分钟登录限流。保留首轮失败日志；测试读取本机登录计数与TTL，接近窗口上限时等待自然过期，不删除Key、不更换IP、不关闭保护，也不对任意业务失败自动重试。
