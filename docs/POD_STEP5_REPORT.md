## 4. 复核时修正

最初调度按图顺序优先领取待确认节点，真实同步调用若永久未知，会阻塞图后面的独立分支。
现在先领取就绪分支，再按最近检查时间处理待确认节点。原租约测试曾假定“过期后立即领取原节点”，
已调整为先完成独立分支，再确认原 submission key 查询与陈旧回写拒绝，保留原安全断言。

生成图片不再强制按 PNG 扩展名归档；依据文件实际内容选择支持的格式，再走完整校验。
图片响应采用与实际格式一致的元数据，JPEG 的中断恢复用例已覆盖。

## 5. 尚未验收与边界

1. **真实模型**：价格页有 2.1 Turbo，但接口指南示例仍以 2.0 为主；账号可用性、请求参数、参考图效果、尺寸、用量与账单须实测。没有 Key 和明确预算前不发付费请求。
2. **预算**：为所有用户累计的固定价格估算，不是供应商硬上限或用户充值钱包；调价须复核。未知调用保留预占，当前没有人工确认/释放操作入口。
3. **过期归档**：签名地址通常约 24 小时过期；下载可重试，过期刷新尚未实现，不能保证长期待归档一定能恢复。
4. **账单展示**：保留所有调用记录，但节点详情主要展示本轮结果，没有按尝试汇总的完整费用页面。不要把节点显示值当成该运行全部历史费用。
5. **兼容与存储**：005 前已提交但响应丢失的模拟请求，若旧请求哈希与新增模式字段不一致，会保守返回 409；先查运行历史，不通过更换请求键盲目重复提交。数据库提交不明时保留文件，可能存在待核查孤立文件，未自动清理。
6. **环境验收**：未完成真实浏览器逐项点击、移动端视觉、供应商异常实测、Linux 部署和数据库/素材整套恢复；组件测试与 HTTP 200 不能替代这些验收。
