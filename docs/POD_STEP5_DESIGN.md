# 第五阶段：千问接入设计

用户已选择同一家供应商，优先控制成本：文字 `qwen-flash`，图片 `qwen-image-2.1-turbo`。
本轮接入服务端适配、私有结果归档、用量记录及界面；没有密钥和明确试跑预算时，不发送付费请求。

## 接口前七项核对

沿用第四阶段运行/素材接口和分页上限，不增加无分页列表。新增查询按调用主键或运行 ID 索引定位，
不逐行加载列表详情。HTTP、数据库、存储使用 context 和超时。权限仍为 `pod:studio:access` 加个人空间；
错误走原 response/BizError，外部错误正文、签名 URL 和密钥不进入 DTO/日志；公开字段仍用 camelCase。

## 执行与费用边界

- 新运行固定 executionMode 和模型 ID；旧测试运行不能因改配置而变成真实调用。
- 默认继续 simulation；真实模式须显式设置 qwen、allowPaidCalls 和本实例累计预算，Worker 从服务端环境变量读密钥。
- 文字上限 2048 输出 Token，输入字节数有界；图片每次 1—4 张，参考图最多 3 张。首版不支持文字节点看图。
- 预算按固定保守单次上限预占，已确认响应按模型用量估算，状态不确定保留预占。单位为百万分之一元整数。
  这是本地估算护栏，不替代供应商账单或供应商侧额度控制；调价后须重新核对价格。
- 原测试额度账本只用于 simulation；真实费用另记调用记录，不把赠送测试单位当人民币。
- 同步接口没有已确认的按客户端请求键查询/幂等保证。提交前持久化调用意图；网络超时、进程中断、5xx
  等不确定结果不重新 Submit，也不伪造成功或无条件退款。
- 先持久化供应商响应和用量，再归档图片。归档失败只重做下载，不能重新生图；上游签名地址过期时明确保留待处理。
- 生成文件进入私有素材库，并与本次运行同事务建立引用。归档幂等键为调用 ID + 图片序号。
- 下载只允许供应商结果域名的 HTTPS、公网地址、固定端口，无认证转发、无跳转，并限制字节数和解码像素。
