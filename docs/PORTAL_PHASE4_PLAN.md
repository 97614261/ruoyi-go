# 第四阶段：模板扩展

> 本文记录该阶段的历史收口快照；当前v13功能与进度见 [功能增强计划](./PORTAL_GROWTH_PLAN.md) 和 [功能增强验收](./PORTAL_GROWTH_ACCEPTANCE.md)。下方“待做”仅指当时状态。
2026-11-02，portal 分支、本地专用门户。执行情况与证据见 [验收报告](./PORTAL_PHASE4_ACCEPTANCE.md)。

| 项目 | 实现 | 边界 |
|---|---|---|
| 行业模板 | 制造与工程 industrial v1，含全部九类页面 | 随代码注册，不接收上传模板或脚本 |
| 栏目布局 | 全局列表布局、最多100个栏目独立网格/列表设置 | 栏目优先；首页及详情不改变；保存草稿、发布及恢复均使用外观版本 |
| 差异预览 | 后台同屏对比已保存草稿与候选模板 | 同一份已取到的公开内容；不保存、不发布，不包含未保存表单 |
| 兼容与验收 | v9能力标记、旧资源哈希、真实权限/发布/回退测试及页面检查 | 仍30表，无业务DDL和自动角色授权 |

新增 GET /cms/site/themes，分页上限100，要求 cms:site:query。
新增 POST /cms/site/compare，要求 cms:site:query；栏目对比还需 cms:channel:query。
图片在后台仍按 cms:asset:query 授权读取，不把Token放在图片URL；外观编辑、发布仍分别要求edit、publish。
对照请求绑定草稿version，过期拒绝；两侧共享已取得的内容数据，并不承诺整个网站的跨查询事务快照。

第三阶段只完成第1项导入导出，素材分组/检索、301迁移、自动保存仍待做；没有因执行本阶段而把它们标为完成。Linux生产实测仍待环境。
