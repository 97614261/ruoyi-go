# POD Studio

基于 RuoYi-Go 主分支开发的 POD AI 创意工作流平台。以“节点卡片 + 连线 + 无限画布”为主要操作方式，把设计要求、参考图、生成、图片处理、商品预览和导出组织成可保存、可重复执行的流程。

创作端首页的「制作商品图」可以复用商品素材包，勾选白底主图、场景图、45° 展示图、侧面图和细节图，报价后执行，完成后选择定稿并按 SKU 打包。也可以使用合适的印花原图创建印花或 T 恤样机画布。现有专用 POD 库使用 `podsetup -mode migrate` 升到 015 后再启动新版。

## 开发与运行边界

- 创作端位于 `studio/`，给普通用户使用；管理端复用 `web/`，给管理员/运营使用。第 2 步接通 web，第 3 步接通模型管理的三个 Tab；普通创作者不能进入后台，其他未实现菜单仍标明后续阶段。
- `sql/pod/` 提供 001—015 的独立初始化与本地升级。006 为个人模板，007 为批量，008 为管理基础，009 为供应商/模型目录，010 为创作者权益和点数/资源账户，011 为报价/绑定/调用计费，012 为官方模板、平台素材及复制记录，013 为商品素材包和商品图项目，014 为各用途的商品图定稿，015 为商品工作类型和所选出图用途。
- 当前数据库为 `pod_studio_dev`，POD 专用 Redis 在 `127.0.0.1:6387`、DB 15；原 6379 未改变。配置与归属标记保护启动，生产仍需专用账号与环境。
- 账号密码记录在忽略提交的 `.local/accounts.json`；登录使用 `pod_creator`，验证码以本地设置为准。2026-11-18 源库 admin 密码与该文件不匹配，未重置；请用当前维护的密码。`admin` 不自动拥有个人工作空间。
- 历史 qwen 模式已验证千问北京地域：文字 `qwen-flash`，图片 `qwen-image-2.1-turbo`。按用户追加试用额度的要求，本机累计估算预算从 1 元提高到 5 元，并发 1；短文字、单参考图、五种比例和两张输出的真实结果见 [边界报告](docs/POD_BOUNDARY_ACCEPTANCE_20261112.md)，控制台账单仍待核对。

## 开发方式

直接在本目录开发即可。每一步交付代码、适用测试和更新后的进度记录，未真实验证的能力明确标记。
仅创建 Git 分支不会自动引入主分支未来改动；后续按需把通用修复从 `main` 合并进来。

第 6、7 步操作和验收见 [任务与官方模板报告](docs/POD_OPERATIONS_CATALOG_REPORT_20261113.md)。

第 5 步操作与验收见 [managed 执行报告](docs/POD_MANAGED_EXECUTION_REPORT_20261113.md)。新增模型须在后台显式配置凭据/规格/价格并授权用户；不能把离线替身、空目录或配置检查当成真实调用成功。

当前本地运行模式为 managed，旧千问 Key 不自动迁入模型目录；没有给既有账号自动授权模型或充值点数。
